LDA 1
=====


Overview
~~~~~~~~

Latent Dirichlet Allocation (LDA) is a generative probabilistic model
used for discovering the underlying topics in a collection of documents.

LDA assumes that:

-  Each document is a mixture of multiple topics.
-  Each topic is a probability distribution over words.
-  Each word in a document is generated by first selecting a topic and
   then selecting a word from that topic.
-  The topic proportions and word distributions are latent variables
   that must be inferred from the observed documents.

LDA is widely used for topic modeling, document classification,
information retrieval, and text mining.

The Topic Modeling Problem
~~~~~~~~~~~~~~~~~~~~~~~~~~

Suppose we have a collection of documents:

.. math::


   D = \{d_1,d_2,\ldots,d_N\}

Each document contains a collection of words.

For example:

-  Document 1: “machine learning neural networks deep learning”
-  Document 2: “football player team game goal”
-  Document 3: “neural networks deep learning model”

We may suspect that the documents are generated from a small number of
underlying topics.

For example:

-  Topic 1: Machine Learning
-  Topic 2: Sports

LDA attempts to discover these topics automatically.

The important idea is that the topics are **latent**. We observe only
the documents and words, not the topics that generated them.

Basic Idea of LDA
~~~~~~~~~~~~~~~~~

LDA represents each document as a mixture of topics.

For example, a document might have:

.. math::


   P(\text{Topic 1}) = 0.7

.. math::


   P(\text{Topic 2}) = 0.2

.. math::


   P(\text{Topic 3}) = 0.1

This means that the document is primarily associated with Topic 1, but
it also contains information related to Topics 2 and 3.

Similarly, each topic is represented as a probability distribution over
words.

Topic: Machine Learning
~~~~~~~~~~~~~~~~~~~~~~~

======== ===========
Word     Probability
======== ===========
learning 0.15
model    0.12
neural   0.10
network  0.08
training 0.07
======== ===========

Topic: Sports
~~~~~~~~~~~~~

====== ===========
Word   Probability
====== ===========
game   0.15
player 0.12
team   0.11
goal   0.09
season 0.07
====== ===========

Thus, LDA learns two important distributions:

1. The distribution of topics for each document.
2. The distribution of words for each topic.

Generative Model
~~~~~~~~~~~~~~~~

LDA is called a **generative model** because it describes a hypothetical
process for generating documents.

The generative process is:

1. Choose the number of topics :math:`K`.
2. For each topic, choose a distribution over words.
3. For each document, choose a distribution over topics.
4. For each word position in the document:

   -  Choose a topic.
   -  Choose a word from that topic.

The observed words are generated from the latent topic assignments.

Notation
~~~~~~~~

Let:

-  :math:`D` = number of documents.
-  :math:`K` = number of topics.
-  :math:`V` = vocabulary size.
-  :math:`N_d` = number of words in document :math:`d`.
-  :math:`w_{dn}` = observed word at position :math:`n` in document
   :math:`d`.
-  :math:`z_{dn}` = topic assignment for word :math:`n` in document
   :math:`d`.
-  :math:`\theta_d` = topic distribution for document :math:`d`.
-  :math:`\phi_k` = word distribution for topic :math:`k`.
-  :math:`\alpha` = Dirichlet prior parameter for document-topic
   distributions.
-  :math:`\beta` = Dirichlet prior parameter for topic-word
   distributions.

The two main latent variables are:

.. math::


   \theta_d

and

.. math::


   \phi_k

where:

.. math::


   \theta_d \sim \mathrm{Dirichlet}(\alpha)

and

.. math::


   \phi_k \sim \mathrm{Dirichlet}(\beta)

Document-Topic Distribution
~~~~~~~~~~~~~~~~~~~~~~~~~~~

For each document :math:`d`, LDA assumes a topic distribution:

.. math::


   \theta_d \sim \mathrm{Dirichlet}(\alpha)

The vector :math:`\theta_d` contains the probability of each topic in
the document.

For example, with three topics:

.. math::


   \theta_d =
   \begin{bmatrix}
   0.6 \\
   0.3 \\
   0.1
   \end{bmatrix}

This means:

-  Topic 1: 60%
-  Topic 2: 30%
-  Topic 3: 10%

The probabilities sum to one:

.. math::


   \sum_{k=1}^{K}\theta_{dk}=1

Topic-Word Distribution
~~~~~~~~~~~~~~~~~~~~~~~

For every topic :math:`k`, LDA defines a probability distribution over
the vocabulary:

.. math::


   \phi_k \sim \mathrm{Dirichlet}(\beta)

For example:

.. math::


   \phi_k =
   \begin{bmatrix}
   0.05 \\
   0.15 \\
   0.10 \\
   0.20 \\
   \vdots
   \end{bmatrix}

Each element represents the probability of a particular word given the
topic.

Therefore:

.. math::


   \sum_{v=1}^{V}\phi_{kv}=1

Generative Process in Detail
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The LDA generative process can be written as follows.

For each topic :math:`k`:

.. math::


   \phi_k \sim \mathrm{Dirichlet}(\beta)

For each document :math:`d`:

.. math::


   \theta_d \sim \mathrm{Dirichlet}(\alpha)

For each word position :math:`n`:

1. Choose a topic:

.. math::


   z_{dn} \sim \mathrm{Categorical}(\theta_d)

2. Choose a word:

.. math::


   w_{dn} \sim \mathrm{Categorical}(\phi_{z_{dn}})

Therefore:

.. math::


   P(w_{dn}\mid z_{dn},\phi)
   =
   \phi_{z_{dn},w_{dn}}
