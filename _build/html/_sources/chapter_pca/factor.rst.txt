PCA vs. Factor Analysis
=======================


Factor analysis encompasses a variety of techniques used for uncovering
the underlying factors or latent variables that explain the observed
data. Each method makes different assumptions about the data and employs
different statistical models. This chapter covers Probabilistic
Principal Component Analysis (PPCA), Gaussian Matrix Factorization, and
Poisson Matrix Factorization.

Probabilistic Principal Component Analysis (PPCA)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Overview
~~~~~~~~

-  **PPCA** is a probabilistic approach to PCA that frames the
   dimensionality reduction problem in a probabilistic context.
-  It models the data as being generated by a set of latent variables
   with added Gaussian noise.

Model
~~~~~

The data :math:`\mathbf{x}_i` is modeled as:

.. math::


   \mathbf{x}_i = \mathbf{W}\mathbf{z}_i + \boldsymbol{\mu} + \boldsymbol{\epsilon}_i

where:

-  :math:`\mathbf{x}_i` is the observed data.
-  :math:`\mathbf{W}` is the factor loading matrix.
-  :math:`\mathbf{z}_i` is the latent variable or factor.
-  :math:`\boldsymbol{\mu}` is the mean vector.
-  :math:`\boldsymbol{\epsilon}_i` is Gaussian noise with covariance
   :math:`\sigma^2\mathbf{I}`.

Characteristics
~~~~~~~~~~~~~~~

-  **Latent Variables:** The latent variables are modeled as
   :math:`\mathbf{z}_i \sim \mathcal{N}(0,\mathbf{I})`.
-  **Maximum Likelihood:** Parameters :math:`\mathbf{W}` and
   :math:`\sigma^2` are estimated using maximum likelihood.
-  **Principal Components:** The principal components in PCA correspond
   to the maximum-likelihood solution in PPCA.

Gaussian Matrix Factorization
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~


.. _model-1:

Overview
~~~~~~~~

Gaussian Matrix Factorization is used to decompose a matrix into
lower-dimensional latent factors under the assumption of Gaussian noise.
It is commonly used in collaborative filtering and recommendation
systems.


.. _characteristics-1:

Model
~~~~~

The data matrix :math:`\mathbf{X}` is decomposed into two
lower-dimensional matrices:

.. math::


   \mathbf{X} \approx \mathbf{U}\mathbf{V}^T

where:

-  :math:`\mathbf{U} \in \mathbb{R}^{n \times k}` is the matrix of
   latent factors for rows.
-  :math:`\mathbf{V} \in \mathbb{R}^{m \times k}` is the matrix of
   latent factors for columns.
-  :math:`k` is the number of latent factors.

The entries of :math:`\mathbf{X}` are assumed to be Gaussian-distributed
around :math:`\mathbf{U}\mathbf{V}^T`.


Characteristics
~~~~~~~~~~~~~~~

-  **Gaussian Noise:** The model assumes Gaussian noise in the observed
   data.
-  **Latent Factors:** It captures latent factors that explain the
   observed data.
-  **Optimization:** It can be solved using alternating least squares or
   stochastic gradient descent.

.. _overview-2:

Poisson Matrix Factorization
~~~~~~~~~~~~~~~~~~~~~~~~~~~~


.. _model-2:

Overview
~~~~~~~~

Poisson Matrix Factorization is used for decomposing count data into
latent factors. It is commonly used for applications such as topic
modeling and collaborative filtering with count data.


.. _characteristics-2:

Model
~~~~~

The data matrix :math:`\mathbf{X}` is assumed to follow a Poisson
distribution:

.. math::


   X_{ij} \sim \operatorname{Poisson}\left((\mathbf{U}\mathbf{V}^T)_{ij}\right)

where:

-  :math:`\mathbf{U} \in \mathbb{R}^{n \times k}` is a non-negative
   latent factor matrix.
-  :math:`\mathbf{V} \in \mathbb{R}^{m \times k}` is a non-negative
   latent factor matrix.
-  :math:`(\mathbf{U}\mathbf{V}^T)_{ij}` is the expected rate parameter
   of the Poisson distribution.


Characteristics
~~~~~~~~~~~~~~~

-  **Poisson Noise:** The observed counts are assumed to follow a
   Poisson distribution.
-  **Non-Negativity:** The latent factors :math:`\mathbf{U}` and
   :math:`\mathbf{V}` are non-negative.
-  **Optimization:** Parameters can be estimated using maximum
   likelihood or Bayesian inference.

Comparison of Factor Analysis Methods
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

+-----------------+-----------------+-----------------+-----------------+
| Factor Analysis | Type of Data    | Assumptions     | Key             |
| Method          |                 |                 | Characteristics |
+=================+=================+=================+=================+
| **PPCA**        | Continuous      | Gaussian noise  | Linear,         |
|                 |                 |                 | probabilistic,  |
|                 |                 |                 | Gaussian latent |
|                 |                 |                 | variables       |
+-----------------+-----------------+-----------------+-----------------+
| **Gaussian      | Continuous      | Gaussian noise  | Latent factor   |
| Matrix          |                 |                 | model with      |
| Factorization** |                 |                 | Gaussian noise  |
+-----------------+-----------------+-----------------+-----------------+
| **Poisson       | Count           | Poisson         | Non-negative    |
| Matrix          |                 | distribution    | factors,        |
| Factorization** |                 |                 | suitable for    |
|                 |                 |                 | count data      |
+-----------------+-----------------+-----------------+-----------------+

.. _gaussian-matrix-factorization-1:

Summary
~~~~~~~

-  **PPCA:** Extends PCA into a probabilistic framework and captures
   linear relationships with Gaussian noise.
-  **Gaussian Matrix Factorization:** Decomposes a data matrix into
   latent factors assuming Gaussian-distributed errors. It is commonly
   used in recommendation systems.
-  **Poisson Matrix Factorization:** Is designed for count data and
   decomposes the data matrix into non-negative latent factors using a
   Poisson distribution.

Each method is suited to different types of data and underlying
assumptions.


Gaussian Matrix Factorization
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Gaussian Matrix Factorization is a commonly used technique for
collaborative filtering, particularly in recommendation systems. The
goal is to factorize a matrix, usually containing user-item ratings,
into two lower-dimensional matrices representing latent factors for
users and items.

The model assumes that the observed entries are noisy observations from
a Gaussian distribution.

Model Formulation
~~~~~~~~~~~~~~~~~

Given an observed data matrix:

.. math::


   R \in \mathbb{R}^{n \times m}

where:

-  :math:`n` is the number of users.
-  :math:`m` is the number of items.

The goal is to approximate :math:`R` using two lower-dimensional
matrices:

.. math::


   R \approx UV^T

where:

-  :math:`U \in \mathbb{R}^{n \times k}` is the user latent factor
   matrix.
-  :math:`V \in \mathbb{R}^{m \times k}` is the item latent factor
   matrix.
-  :math:`k` is the number of latent factors.

The entries of :math:`R` are assumed to be Gaussian-distributed around
:math:`UV^T`.

Objective Function
~~~~~~~~~~~~~~~~~~

The objective is to minimize the squared difference between observed and
predicted entries while using regularization to prevent overfitting:

.. math::


   \min_{U,V}
   \sum_{(i,j)\in\mathcal{O}}
   (R_{ij}-U_iV_j^T)^2
   +
   \lambda
   \left(
   \|U\|_F^2+\|V\|_F^2
   \right)

where:

-  :math:`\mathcal{O}` is the set of observed entries.
-  :math:`\lambda` is the regularization parameter.
-  :math:`\|U\|_F^2` and :math:`\|V\|_F^2` are Frobenius norms.

Solving Using Alternating Least Squares
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Alternating Least Squares (ALS) is an iterative optimization technique
in which one matrix is fixed while the other is optimized.

Step 1: Initialize
~~~~~~~~~~~~~~~~~~

Initialize :math:`U` and :math:`V` with random values or another
suitable initialization strategy.

Step 2: Optimize :math:`U` Given :math:`V`
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

For each user :math:`i`, solve:

.. math::


   U_i =
   \left(
   \sum_{j\in\mathcal{O}_i}
   V_jV_j^T
   +
   \lambda I
   \right)^{-1}
   \left(
   \sum_{j\in\mathcal{O}_i}
   R_{ij}V_j
   \right)

where :math:`\mathcal{O}_i` is the set of items rated by user :math:`i`.

Step 3: Optimize :math:`V` Given :math:`U`
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

For each item :math:`j`, solve:

.. math::


   V_j =
   \left(
   \sum_{i\in\mathcal{O}_j}
   U_iU_i^T
   +
   \lambda I
   \right)^{-1}
   \left(
   \sum_{i\in\mathcal{O}_j}
   R_{ij}U_i
   \right)

where :math:`\mathcal{O}_j` is the set of users who rated item
:math:`j`.

Step 4: Iterate
~~~~~~~~~~~~~~~

Repeat the updates of :math:`U` and :math:`V` until convergence.

A common convergence criterion is that the change in the objective
function, :math:`U`, and :math:`V` becomes smaller than a predefined
threshold.

Gaussian Matrix Factorization in a Probabilistic Context
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Probabilistic Model
~~~~~~~~~~~~~~~~~~~

In probabilistic Gaussian Matrix Factorization, the observed matrix
:math:`R` is assumed to be generated by a probabilistic process
involving latent variables for users and items.

Model Assumptions
~~~~~~~~~~~~~~~~~

1. Latent Factors
^^^^^^^^^^^^^^^^^

Each user :math:`i` is associated with a latent vector:

.. math::


   \mathbf{u}_i \in \mathbb{R}^k

Each item :math:`j` is associated with a latent vector:

.. math::


   \mathbf{v}_j \in \mathbb{R}^k

2. Observed Ratings
^^^^^^^^^^^^^^^^^^^

The observed rating :math:`R_{ij}` is modeled as:

.. math::


   R_{ij}
   \sim
   \mathcal{N}
   \left(
   \mathbf{u}_i^T\mathbf{v}_j,
   \sigma^2
   \right)

3. Priors on Latent Factors
^^^^^^^^^^^^^^^^^^^^^^^^^^^

The latent factors are assigned Gaussian priors:

.. math::


   \mathbf{u}_i
   \sim
   \mathcal{N}
   \left(
   \mathbf{0},
   \lambda_u^{-1}I
   \right)

and

.. math::


   \mathbf{v}_j
   \sim
   \mathcal{N}
   \left(
   \mathbf{0},
   \lambda_v^{-1}I
   \right)

Here, :math:`\lambda_u` and :math:`\lambda_v` are precision parameters,
which are the inverse of variance.

Probabilistic Formulation
~~~~~~~~~~~~~~~~~~~~~~~~~

The likelihood of the observed data is:

.. math::


   p(R\mid U,V,\sigma^2)
   =
   \prod_{(i,j)\in\mathcal{O}}
   \mathcal{N}
   \left(
   R_{ij}
   \mid
   \mathbf{u}_i^T\mathbf{v}_j,
   \sigma^2
   \right)

The prior distributions are:

.. math::


   p(U\mid\lambda_u)
   =
   \prod_{i=1}^{n}
   \mathcal{N}
   \left(
   \mathbf{u}_i
   \mid
   \mathbf{0},
   \lambda_u^{-1}I
   \right)

and

.. math::


   p(V\mid\lambda_v)
   =
   \prod_{j=1}^{m}
   \mathcal{N}
   \left(
   \mathbf{v}_j
   \mid
   \mathbf{0},
   \lambda_v^{-1}I
   \right)

Posterior Distribution
~~~~~~~~~~~~~~~~~~~~~~

The posterior distribution is proportional to the product of the
likelihood and the priors:

.. math::


   p(U,V\mid R,\sigma^2,\lambda_u,\lambda_v)
   \propto
   p(R\mid U,V,\sigma^2)
   p(U\mid\lambda_u)
   p(V\mid\lambda_v)

Maximizing the Posterior
~~~~~~~~~~~~~~~~~~~~~~~~

Maximizing the posterior is equivalent to minimizing the negative
log-posterior:

.. math::


   \mathcal{L}
   =
   \sum_{(i,j)\in\mathcal{O}}
   \frac{
   (R_{ij}-\mathbf{u}_i^T\mathbf{v}_j)^2
   }{
   2\sigma^2
   }
   +
   \frac{\lambda_u}{2}
   \sum_{i=1}^{n}
   \|\mathbf{u}_i\|^2
   +
   \frac{\lambda_v}{2}
   \sum_{j=1}^{m}
   \|\mathbf{v}_j\|^2

The update for :math:`\mathbf{u}_i` is:

.. math::


   \mathbf{u}_i
   =
   \left(
   \sum_{j\in\mathcal{O}_i}
   \mathbf{v}_j\mathbf{v}_j^T
   +
   \lambda_u\sigma^2I
   \right)^{-1}
   \left(
   \sum_{j\in\mathcal{O}_i}
   R_{ij}\mathbf{v}_j
   \right)

Similarly, the update for :math:`\mathbf{v}_j` is:

.. math::


   \mathbf{v}_j
   =
   \left(
   \sum_{i\in\mathcal{O}_j}
   \mathbf{u}_i\mathbf{u}_i^T
   +
   \lambda_v\sigma^2I
   \right)^{-1}
   \left(
   \sum_{i\in\mathcal{O}_j}
   R_{ij}\mathbf{u}_i
   \right)

Log-Likelihood
~~~~~~~~~~~~~~

Taking the logarithm of the likelihood:

.. math::


   \log p(R\mid U,V,\sigma^2)
   =
   -\frac{1}{2\sigma^2}
   \sum_{(i,j)\in\mathcal{O}}
   (R_{ij}-\mathbf{u}_i^T\mathbf{v}_j)^2
   -
   \frac{|\mathcal{O}|}{2}
   \log(2\pi\sigma^2)

Priors
~~~~~~

The priors on the latent factors are:

.. math::


   p(\mathbf{u}_i)
   =
   \mathcal{N}
   \left(
   \mathbf{u}_i
   \mid
   \mathbf{0},
   \lambda_u^{-1}I
   \right)

and

.. math::


   p(\mathbf{v}_j)
   =
   \mathcal{N}
   \left(
   \mathbf{v}_j
   \mid
   \mathbf{0},
   \lambda_v^{-1}I
   \right)

Taking the logarithm:

.. math::


   \log p(\mathbf{u}_i)
   =
   -\frac{\lambda_u}{2}
   \|\mathbf{u}_i\|^2
   -
   \frac{k}{2}
   \log(2\pi\lambda_u^{-1})

and

.. math::


   \log p(\mathbf{v}_j)
   =
   -\frac{\lambda_v}{2}
   \|\mathbf{v}_j\|^2
   -
   \frac{k}{2}
   \log(2\pi\lambda_v^{-1})

Posterior
~~~~~~~~~

The log posterior is:

.. math::


   \log p(U,V\mid R,\sigma^2,\lambda_u,\lambda_v)
   =
   \log p(R\mid U,V,\sigma^2)
   +
   \sum_i\log p(\mathbf{u}_i)
   +
   \sum_j\log p(\mathbf{v}_j)

Maximum A Posteriori Estimation
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The MAP objective is:

.. math::


   \mathcal{L}
   =
   \frac{1}{2\sigma^2}
   \sum_{(i,j)\in\mathcal{O}}
   (R_{ij}-\mathbf{u}_i^T\mathbf{v}_j)^2
   +
   \frac{\lambda_u}{2}
   \sum_{i=1}^{n}
   \|\mathbf{u}_i\|^2
   +
   \frac{\lambda_v}{2}
   \sum_{j=1}^{m}
   \|\mathbf{v}_j\|^2

Taking the partial derivative with respect to :math:`\mathbf{u}_i`:

.. math::


   \frac{\partial\mathcal{L}}
   {\partial\mathbf{u}_i}
   =
   -\frac{1}{\sigma^2}
   \sum_{j\in\mathcal{O}_i}
   (R_{ij}-\mathbf{u}_i^T\mathbf{v}_j)\mathbf{v}_j
   +
   \lambda_u\mathbf{u}_i

Setting the derivative to zero:

.. math::


   \sum_{j\in\mathcal{O}_i}
   (R_{ij}-\mathbf{u}_i^T\mathbf{v}_j)
   \mathbf{v}_j
   =
   \sigma^2\lambda_u\mathbf{u}_i

Rearranging:

.. math::


   \sum_{j\in\mathcal{O}_i}
   R_{ij}\mathbf{v}_j
   =
   \left(
   \sum_{j\in\mathcal{O}_i}
   \mathbf{v}_j\mathbf{v}_j^T
   +
   \sigma^2\lambda_uI
   \right)
   \mathbf{u}_i

Therefore:

.. math::


   \boxed{
   \mathbf{u}_i
   =
   \left(
   \sum_{j\in\mathcal{O}_i}
   \mathbf{v}_j\mathbf{v}_j^T
   +
   \sigma^2\lambda_uI
   \right)^{-1}
   \left(
   \sum_{j\in\mathcal{O}_i}
   R_{ij}\mathbf{v}_j
   \right)
   }

This is the MAP update equation for :math:`\mathbf{u}_i`.

Non-Negativity in Gaussian Matrix Factorization
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Non-negativity is not normally enforced in Gaussian Matrix
Factorization. GMF does not inherently require latent factors to be
non-negative.

However, non-negativity may be useful when latent factors need to be
interpretable or when the application requires positive components.

One common alternative is **Non-Negative Matrix Factorization (NMF)**,
which explicitly constrains the latent factors to be non-negative.

Another option is to enforce non-negativity directly during optimization
using projected gradient descent.

.. _poisson-matrix-factorization-1:

Projected Gradient Descent
~~~~~~~~~~~~~~~~~~~~~~~~~~

After a gradient update, project each element onto the non-negative
domain.

For :math:`U`:

.. math::


   \mathbf{u}_i
   \leftarrow
   \mathbf{u}_i
   -
   \eta
   \frac{\partial\mathcal{L}}
   {\partial\mathbf{u}_i}

Then:

.. math::


   \mathbf{u}_i
   \leftarrow
   \max(\mathbf{u}_i,0)

Similarly, for :math:`V`:

.. math::


   \mathbf{v}_j
   \leftarrow
   \mathbf{v}_j
   -
   \eta
   \frac{\partial\mathcal{L}}
   {\partial\mathbf{v}_j}

Then:

.. math::


   \mathbf{v}_j
   \leftarrow
   \max(\mathbf{v}_j,0)

where :math:`\eta` is the learning rate.

Poisson Matrix Factorization
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Poisson Matrix Factorization (PMF) is used for decomposing count data
into latent factors. The observed entries are assumed to follow a
Poisson distribution, and the latent factors are non-negative.


.. _objective-function-1:

Probabilistic Model
~~~~~~~~~~~~~~~~~~~

Given an observed count matrix :math:`R`, we approximate it using:

.. math::


   R \approx UV^T

The model assumes:

.. math::


   R_{ij}
   \sim
   \operatorname{Poisson}
   \left(
   (UV^T)_{ij}
   \right)

The latent factors satisfy:

.. math::


   \mathbf{u}_i \geq 0

and

.. math::


   \mathbf{v}_j \geq 0


Objective Function
~~~~~~~~~~~~~~~~~~

The Poisson log-likelihood is:

.. math::


   \log p(R\mid U,V)
   =
   \sum_{(i,j)\in\mathcal{O}}
   \left[
   R_{ij}
   \log((UV^T)_{ij})
   -
   (UV^T)_{ij}
   \right]
   -
   \sum_{(i,j)\in\mathcal{O}}
   \log(R_{ij}!)

Multiplicative Updates
~~~~~~~~~~~~~~~~~~~~~~

For fixed :math:`V`, the update for :math:`U` is:

.. math::


   U_{ik}
   \leftarrow
   U_{ik}
   \frac{
   \sum_j
   R_{ij}
   \frac{V_{jk}}{(UV^T)_{ij}}
   }{
   \sum_j V_{jk}
   }

For fixed :math:`U`, the update for :math:`V` is:

.. math::


   V_{jk}
   \leftarrow
   V_{jk}
   \frac{
   \sum_i
   R_{ij}
   \frac{U_{ik}}{(UV^T)_{ij}}
   }{
   \sum_i U_{ik}
   }

These multiplicative updates preserve non-negativity provided that
:math:`U` and :math:`V` are initialized with non-negative values.

Derivation of the Poisson Matrix Factorization Update
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~


Probabilistic Model
^^^^^^^^^^^^^^^^^^^

The observed counts are modeled as:

.. math::


   R_{ij}
   \sim
   \operatorname{Poisson}
   (\lambda_{ij})

where:

.. math::


   \lambda_{ij}
   =
   \mathbf{u}_i^T\mathbf{v}_j


Log-Likelihood
^^^^^^^^^^^^^^

The likelihood is:

.. math::


   p(R\mid U,V)
   =
   \prod_{(i,j)\in\mathcal{O}}
   \operatorname{Poisson}
   (R_{ij}\mid\mathbf{u}_i^T\mathbf{v}_j)

The Poisson probability mass function is:

.. math::


   \operatorname{Poisson}(R_{ij}\mid\lambda_{ij})
   =
   \frac{
   \lambda_{ij}^{R_{ij}}
   e^{-\lambda_{ij}}
   }{
   R_{ij}!
   }

Therefore:

.. math::


   \log p(R\mid U,V)
   =
   \sum_{(i,j)\in\mathcal{O}}
   \left[
   R_{ij}
   \log(\mathbf{u}_i^T\mathbf{v}_j)
   -
   \mathbf{u}_i^T\mathbf{v}_j
   -
   \log(R_{ij}!)
   \right]

Gradient with Respect to :math:`\mathbf{u}_i`
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

The factorial term is constant with respect to :math:`\mathbf{u}_i`, so
it can be ignored during differentiation.

We obtain:

.. math::


   \frac{
   \partial\log p(R\mid U,V)
   }{
   \partial\mathbf{u}_i
   }
   =
   \sum_{j\in\mathcal{O}_i}
   \left[
   R_{ij}
   \frac{\mathbf{v}_j}
   {\mathbf{u}_i^T\mathbf{v}_j}
   -
   \mathbf{v}_j
   \right]

or equivalently:

.. math::


   \frac{
   \partial\log p(R\mid U,V)
   }{
   \partial\mathbf{u}_i
   }
   =
   \sum_{j\in\mathcal{O}_i}
   \left[
   \frac{R_{ij}\mathbf{v}_j}
   {\mathbf{u}_i^T\mathbf{v}_j}
   -
   \mathbf{v}_j
   \right]

Multiplicative Update
^^^^^^^^^^^^^^^^^^^^^

Setting the gradient to zero gives:

.. math::


   \sum_{j\in\mathcal{O}_i}
   \frac{R_{ij}\mathbf{v}_j}
   {\mathbf{u}_i^T\mathbf{v}_j}
   =
   \sum_{j\in\mathcal{O}_i}
   \mathbf{v}_j

The multiplicative update is:

.. math::


   \boxed{
   \mathbf{u}_i
   \leftarrow
   \mathbf{u}_i
   \circ
   \frac{
   \sum_{j\in\mathcal{O}_i}
   R_{ij}
   \frac{\mathbf{v}_j}
   {\mathbf{u}_i^T\mathbf{v}_j}
   }{
   \sum_{j\in\mathcal{O}_i}
   \mathbf{v}_j
   }
   }

where :math:`\circ` denotes element-wise multiplication.

Poisson Matrix Factorization with Gamma Priors
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

Gamma priors are commonly used for non-negative latent factors and can
encourage sparsity.


Probabilistic Model
~~~~~~~~~~~~~~~~~~~

The observed counts are:

.. math::


   R_{ij}
   \sim
   \operatorname{Poisson}
   (\mathbf{u}_i^T\mathbf{v}_j)

The latent factors have Gamma priors:

.. math::


   u_{ik}
   \sim
   \operatorname{Gamma}
   (\alpha_u,\beta_u)

and:

.. math::


   v_{jk}
   \sim
   \operatorname{Gamma}
   (\alpha_v,\beta_v)

The Gamma density is:

.. math::


   \operatorname{Gamma}(x\mid\alpha,\beta)
   =
   \frac{
   \beta^\alpha
   x^{\alpha-1}
   e^{-\beta x}
   }{
   \Gamma(\alpha)
   }

where :math:`\alpha` is the shape parameter and :math:`\beta` is the
rate parameter.

Joint Log-Likelihood
~~~~~~~~~~~~~~~~~~~~

Ignoring constants independent of :math:`U` and :math:`V`:

.. math::


   \log p(R,U,V)
   =
   \sum_{(i,j)\in\mathcal{O}}
   \left[
   R_{ij}
   \log(\mathbf{u}_i^T\mathbf{v}_j)
   -
   \mathbf{u}_i^T\mathbf{v}_j
   \right]

.. math::


   +
   \sum_{i,k}
   \left[
   (\alpha_u-1)\log u_{ik}
   -
   \beta_u u_{ik}
   \right]

.. math::


   +
   \sum_{j,k}
   \left[
   (\alpha_v-1)\log v_{jk}
   -
   \beta_v v_{jk}
   \right]

Gradient with Respect to :math:`u_{ik}`
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The derivative is:

.. math::


   \frac{
   \partial\log p(R,U,V)
   }{
   \partial u_{ik}
   }
   =
   \sum_{j\in\mathcal{O}_i}
   \left[
   R_{ij}
   \frac{v_{jk}}
   {\mathbf{u}_i^T\mathbf{v}_j}
   -
   v_{jk}
   \right]
   +
   \frac{\alpha_u-1}{u_{ik}}
   -
   \beta_u

Similarly, for :math:`v_{jk}`:

.. math::


   \frac{
   \partial\log p(R,U,V)
   }{
   \partial v_{jk}
   }
   =
   \sum_{i\in\mathcal{O}_j}
   \left[
   R_{ij}
   \frac{u_{ik}}
   {\mathbf{u}_i^T\mathbf{v}_j}
   -
   u_{ik}
   \right]
   +
   \frac{\alpha_v-1}{v_{jk}}
   -
   \beta_v

Multiplicative Updates with Gamma Priors
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

A commonly used multiplicative update form for :math:`U` is:

.. math::


   u_{ik}
   \leftarrow
   u_{ik}
   \frac{
   \displaystyle
   \sum_{j\in\mathcal{O}_i}
   R_{ij}
   \frac{v_{jk}}
   {\mathbf{u}_i^T\mathbf{v}_j}
   +
   \alpha_u-1
   }{
   \displaystyle
   \sum_{j\in\mathcal{O}_i}
   v_{jk}
   +
   \beta_u
   }

Similarly, for :math:`V`:

.. math::


   v_{jk}
   \leftarrow
   v_{jk}
   \frac{
   \displaystyle
   \sum_{i\in\mathcal{O}_j}
   R_{ij}
   \frac{u_{ik}}
   {\mathbf{u}_i^T\mathbf{v}_j}
   +
   \alpha_v-1
   }{
   \displaystyle
   \sum_{i\in\mathcal{O}_j}
   u_{ik}
   +
   \beta_v
   }

These updates preserve non-negativity when initialized with positive
values.

   **Note:** The exact multiplicative-update form depends on the
   optimization derivation and parameterization of the Gamma prior. The
   equations above correspond to a common gradient-based construction. A
   fully Bayesian treatment instead uses variational inference or Gibbs
   sampling.

Poisson Matrix Factorization with Gamma Priors and ELBO
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

A more principled Bayesian approach to Poisson Matrix Factorization with
Gamma priors uses variational inference.

Variational Inference with Auxiliary Variables
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Variational inference approximates the true posterior with a simpler
distribution that can be optimized efficiently.

The model is:

.. math::


   R_{ij}
   \sim
   \operatorname{Poisson}
   (\mathbf{u}_i^T\mathbf{v}_j)

with priors:

.. math::


   u_{ik}
   \sim
   \operatorname{Gamma}
   (\alpha_u,\beta_u)

and:

.. math::


   v_{jk}
   \sim
   \operatorname{Gamma}
   (\alpha_v,\beta_v)

Variational Distribution
~~~~~~~~~~~~~~~~~~~~~~~~

We use a mean-field approximation:

.. math::


   q(U,V)
   =
   \prod_{i,k}
   q(u_{ik})
   \prod_{j,k}
   q(v_{jk})

where:

.. math::


   q(u_{ik})
   =
   \operatorname{Gamma}
   (
   \tilde{\alpha}_{u_{ik}},
   \tilde{\beta}_{u_{ik}}
   )

and:

.. math::


   q(v_{jk})
   =
   \operatorname{Gamma}
   (
   \tilde{\alpha}_{v_{jk}},
   \tilde{\beta}_{v_{jk}}
   )

The variational parameters are:

-  :math:`\tilde{\alpha}`: variational shape parameter.
-  :math:`\tilde{\beta}`: variational rate parameter.

Evidence Lower Bound
~~~~~~~~~~~~~~~~~~~~

The Evidence Lower Bound (ELBO) is:

.. math::


   \operatorname{ELBO}
   =
   \mathbb{E}_q
   [
   \log p(R,U,V)
   ]
   -
   \mathbb{E}_q
   [
   \log q(U,V)
   ]

Maximizing the ELBO makes the variational approximation closer to the
true posterior.

Expected Log-Likelihood
~~~~~~~~~~~~~~~~~~~~~~~

The expected log-likelihood is:

.. math::


   \mathbb{E}_q
   [
   \log p(R\mid U,V)
   ]
   =
   \sum_{(i,j)\in\mathcal{O}}
   \mathbb{E}_q
   \left[
   R_{ij}
   \log(\mathbf{u}_i^T\mathbf{v}_j)
   -
   \mathbf{u}_i^T\mathbf{v}_j
   \right]
   +
   \text{const}

The expectation of the rate parameter is:

.. math::


   \mathbb{E}_q
   [
   \mathbf{u}_i^T\mathbf{v}_j
   ]
   =
   \sum_k
   \mathbb{E}_q[u_{ik}]
   \mathbb{E}_q[v_{jk}]

For a Gamma random variable:

.. math::


   \mathbb{E}[u_{ik}]
   =
   \frac{
   \tilde{\alpha}_{u_{ik}}
   }{
   \tilde{\beta}_{u_{ik}}
   }

and:

.. math::


   \mathbb{E}[v_{jk}]
   =
   \frac{
   \tilde{\alpha}_{v_{jk}}
   }{
   \tilde{\beta}_{v_{jk}}
   }

Therefore:

.. math::


   \mathbb{E}_q
   [
   \mathbf{u}_i^T\mathbf{v}_j
   ]
   =
   \sum_k
   \frac{
   \tilde{\alpha}_{u_{ik}}
   }{
   \tilde{\beta}_{u_{ik}}
   }
   \frac{
   \tilde{\alpha}_{v_{jk}}
   }{
   \tilde{\beta}_{v_{jk}}
   }

Prior Term
~~~~~~~~~~

For :math:`U`:

.. math::


   \mathbb{E}_q[\log p(U)]
   =
   \sum_{i,k}
   \left[
   (\alpha_u-1)
   \mathbb{E}_q[\log u_{ik}]
   -
   \beta_u
   \mathbb{E}_q[u_{ik}]
   \right]
   +
   \text{const}

For a Gamma distribution:

.. math::


   \mathbb{E}_q[\log u_{ik}]
   =
   \psi(
   \tilde{\alpha}_{u_{ik}}
   )
   -
   \log
   \tilde{\beta}_{u_{ik}}

and:

.. math::


   \mathbb{E}_q[u_{ik}]
   =
   \frac{
   \tilde{\alpha}_{u_{ik}}
   }{
   \tilde{\beta}_{u_{ik}}
   }

Therefore:

.. math::


   \mathbb{E}_q[\log p(U)]
   =
   \sum_{i,k}
   \left[
   (\alpha_u-1)
   \left(
   \psi(\tilde{\alpha}_{u_{ik}})
   -
   \log\tilde{\beta}_{u_{ik}}
   \right)
   -
   \beta_u
   \frac{
   \tilde{\alpha}_{u_{ik}}
   }{
   \tilde{\beta}_{u_{ik}}
   }
   \right]
   +
   \text{const}

A corresponding expression applies to :math:`V`.

Entropy Term
~~~~~~~~~~~~

The entropy contribution can be written through:

.. math::


   -\mathbb{E}_q[\log q(U)]

and:

.. math::


   -\mathbb{E}_q[\log q(V)]

For the Gamma variational distribution:

.. math::


   \mathbb{E}_q[\log u_{ik}]
   =
   \psi(
   \tilde{\alpha}_{u_{ik}}
   )
   -
   \log
   \tilde{\beta}_{u_{ik}}

and:

.. math::


   \mathbb{E}_q[u_{ik}]
   =
   \frac{
   \tilde{\alpha}_{u_{ik}}
   }{
   \tilde{\beta}_{u_{ik}}
   }

These quantities are used to evaluate the ELBO.

Variational Updates
~~~~~~~~~~~~~~~~~~~

The variational parameters are updated iteratively.

A useful quantity for the expected contribution of component :math:`k`
to observation :math:`(i,j)` is:

.. math::


   \phi_{ijk}
   =
   \frac{
   \mathbb{E}_q[u_{ik}]
   \mathbb{E}_q[v_{jk}]
   }{
   \sum_{\ell}
   \mathbb{E}_q[u_{i\ell}]
   \mathbb{E}_q[v_{j\ell}]
   }

where:

.. math::


   \sum_k \phi_{ijk}=1

The expected number of observations assigned to component :math:`k` is:

.. math::


   \hat{R}_{ijk}
   =
   R_{ij}\phi_{ijk}

Update for :math:`u_{ik}`
~~~~~~~~~~~~~~~~~~~~~~~~~

The variational shape parameter becomes:

.. math::


   \tilde{\alpha}_{u_{ik}}
   =
   \alpha_u
   +
   \sum_{j\in\mathcal{O}_i}
   \hat{R}_{ijk}

The variational rate parameter becomes:

.. math::


   \tilde{\beta}_{u_{ik}}
   =
   \beta_u
   +
   \sum_{j\in\mathcal{O}_i}
   \mathbb{E}_q[v_{jk}]

Therefore:

.. math::


   q(u_{ik})
   =
   \operatorname{Gamma}
   (
   \tilde{\alpha}_{u_{ik}},
   \tilde{\beta}_{u_{ik}}
   )

with posterior mean:

.. math::


   \mathbb{E}_q[u_{ik}]
   =
   \frac{
   \tilde{\alpha}_{u_{ik}}
   }{
   \tilde{\beta}_{u_{ik}}
   }

Update for :math:`v_{jk}`
~~~~~~~~~~~~~~~~~~~~~~~~~

Similarly:

.. math::


   \tilde{\alpha}_{v_{jk}}
   =
   \alpha_v
   +
   \sum_{i\in\mathcal{O}_j}
   \hat{R}_{ijk}

and:

.. math::


   \tilde{\beta}_{v_{jk}}
   =
   \beta_v
   +
   \sum_{i\in\mathcal{O}_j}
   \mathbb{E}_q[u_{ik}]

Therefore:

.. math::


   q(v_{jk})
   =
   \operatorname{Gamma}
   (
   \tilde{\alpha}_{v_{jk}},
   \tilde{\beta}_{v_{jk}}
   )

with posterior mean:

.. math::


   \mathbb{E}_q[v_{jk}]
   =
   \frac{
   \tilde{\alpha}_{v_{jk}}
   }{
   \tilde{\beta}_{v_{jk}}
   }

Solving for the Variational Parameters
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

For :math:`u_{ik}`, the variational distribution is:

.. math::


   q(u_{ik})
   =
   \operatorname{Gamma}
   (
   \tilde{\alpha}_{u_{ik}},
   \tilde{\beta}_{u_{ik}}
   )

The expected value is:

.. math::


   \mathbb{E}_q[u_{ik}]
   =
   \frac{
   \tilde{\alpha}_{u_{ik}}
   }{
   \tilde{\beta}_{u_{ik}}
   }

and the expected logarithm is:

.. math::


   \mathbb{E}_q[\log u_{ik}]
   =
   \psi(
   \tilde{\alpha}_{u_{ik}}
   )
   -
   \log
   \tilde{\beta}_{u_{ik}}

The corresponding expressions for :math:`v_{jk}` are:

.. math::


   \mathbb{E}_q[v_{jk}]
   =
   \frac{
   \tilde{\alpha}_{v_{jk}}
   }{
   \tilde{\beta}_{v_{jk}}
   }

and:

.. math::


   \mathbb{E}_q[\log v_{jk}]
   =
   \psi(
   \tilde{\alpha}_{v_{jk}}
   )
   -
   \log
   \tilde{\beta}_{v_{jk}}

Expected Rate
~~~~~~~~~~~~~

The expected Poisson rate is:

.. math::


   \mathbb{E}_q[\lambda_{ij}]
   =
   \sum_k
   \mathbb{E}_q[u_{ik}]
   \mathbb{E}_q[v_{jk}]

or:

.. math::


   \mathbb{E}_q[\lambda_{ij}]
   =
   \sum_k
   \frac{
   \tilde{\alpha}_{u_{ik}}
   }{
   \tilde{\beta}_{u_{ik}}
   }
   \frac{
   \tilde{\alpha}_{v_{jk}}
   }{
   \tilde{\beta}_{v_{jk}}
   }

This expected rate is used when updating the auxiliary responsibility
variables :math:`\phi_{ijk}`.

.. _step-1-initialize-1:

Complete Variational Inference Algorithm
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The overall algorithm can be summarized as follows.


Step 1: Initialize
~~~~~~~~~~~~~~~~~~

Initialize positive variational parameters:

.. math::


   \tilde{\alpha}_{u_{ik}},
   \tilde{\beta}_{u_{ik}},
   \tilde{\alpha}_{v_{jk}},
   \tilde{\beta}_{v_{jk}}

Step 2: Compute Expected Latent Factors
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Compute:

.. math::


   \mathbb{E}[u_{ik}]
   =
   \frac{
   \tilde{\alpha}_{u_{ik}}
   }{
   \tilde{\beta}_{u_{ik}}
   }

and:

.. math::


   \mathbb{E}[v_{jk}]
   =
   \frac{
   \tilde{\alpha}_{v_{jk}}
   }{
   \tilde{\beta}_{v_{jk}}
   }

Step 3: Compute Responsibilities
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

For each observed entry:

.. math::


   \phi_{ijk}
   =
   \frac{
   \mathbb{E}[u_{ik}]
   \mathbb{E}[v_{jk}]
   }{
   \sum_{\ell}
   \mathbb{E}[u_{i\ell}]
   \mathbb{E}[v_{j\ell}]
   }

Step 4: Compute Expected Counts
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. math::


   \hat{R}_{ijk}
   =
   R_{ij}\phi_{ijk}

Step 5: Update :math:`U`
~~~~~~~~~~~~~~~~~~~~~~~~

Update:

.. math::


   \tilde{\alpha}_{u_{ik}}
   =
   \alpha_u
   +
   \sum_{j\in\mathcal{O}_i}
   \hat{R}_{ijk}

and:

.. math::


   \tilde{\beta}_{u_{ik}}
   =
   \beta_u
   +
   \sum_{j\in\mathcal{O}_i}
   \mathbb{E}[v_{jk}]

Step 6: Update :math:`V`
~~~~~~~~~~~~~~~~~~~~~~~~

Update:

.. math::


   \tilde{\alpha}_{v_{jk}}
   =
   \alpha_v
   +
   \sum_{i\in\mathcal{O}_j}
   \hat{R}_{ijk}

and:

.. math::


   \tilde{\beta}_{v_{jk}}
   =
   \beta_v
   +
   \sum_{i\in\mathcal{O}_j}
   \mathbb{E}[u_{ik}]

.. _summary-1:

Step 7: Repeat
~~~~~~~~~~~~~~

Repeat Steps 2–6 until the ELBO or another convergence criterion
stabilizes.


Summary
~~~~~~~

The major factorization methods discussed in this chapter differ
primarily in their assumptions about the observed data.

-  **PPCA** uses a probabilistic model with Gaussian noise and linear
   latent variables.
-  **Gaussian Matrix Factorization** models continuous observations
   using Gaussian noise and latent user/item factors.
-  **Poisson Matrix Factorization** models count observations using
   Poisson distributions and non-negative latent factors.
-  **Gamma Priors** provide a natural Bayesian prior for non-negative
   latent factors.
-  **Variational Inference** approximates the posterior using a
   tractable family of distributions.
-  **The ELBO** provides the objective that is optimized during
   variational inference.
-  **Auxiliary variables** allow the Poisson likelihood to be handled
   using simpler conditional updates.
-  **Gamma variational distributions** provide closed-form updates for
   the variational shape and rate parameters.

The key distinction is the observation model:

.. math::


   \boxed{
   \text{Continuous data}
   \rightarrow
   \text{Gaussian models}
   }

and:

.. math::


   \boxed{
   \text{Count data}
   \rightarrow
   \text{Poisson models}
   }

For Bayesian Poisson Matrix Factorization:

.. math::


   \boxed{
   \text{Poisson likelihood}
   +
   \text{Gamma priors}
   +
   \text{Variational inference}
   \rightarrow
   \text{Gamma posterior approximations}
   }

This framework provides a flexible approach for modeling sparse count
data while maintaining non-negative and interpretable latent
representations.
