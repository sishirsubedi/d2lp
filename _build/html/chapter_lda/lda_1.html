3.3.1. Overview¶

Latent Dirichlet Allocation (LDA) is a generative probabilistic model used for discovering the underlying topics in a collection of documents.

LDA assumes that:

  • Each document is a mixture of multiple topics.

  • Each topic is a probability distribution over words.

  • Each word in a document is generated by first selecting a topic and then selecting a word from that topic.

  • The topic proportions and word distributions are latent variables that must be inferred from the observed documents.

LDA is widely used for topic modeling, document classification, information retrieval, and text mining.

3.3.2. The Topic Modeling Problem¶

Suppose we have a collection of documents:

(3.3.1)¶\[D = \{d_1,d_2,\ldots,d_N\}\]

Each document contains a collection of words.

For example:

  • Document 1: “machine learning neural networks deep learning”

  • Document 2: “football player team game goal”

  • Document 3: “neural networks deep learning model”

We may suspect that the documents are generated from a small number of underlying topics.

For example:

  • Topic 1: Machine Learning

  • Topic 2: Sports

LDA attempts to discover these topics automatically.

The important idea is that the topics are latent. We observe only the documents and words, not the topics that generated them.

3.3.3. Basic Idea of LDA¶

LDA represents each document as a mixture of topics.

For example, a document might have:

(3.3.2)¶\[P(\text{Topic 1}) = 0.7\]
(3.3.3)¶\[P(\text{Topic 2}) = 0.2\]
(3.3.4)¶\[P(\text{Topic 3}) = 0.1\]

This means that the document is primarily associated with Topic 1, but it also contains information related to Topics 2 and 3.

Similarly, each topic is represented as a probability distribution over words.

Thus, LDA learns two important distributions:

  1. The distribution of topics for each document.

  2. The distribution of words for each topic.

3.3.6. Generative Model¶

LDA is called a generative model because it describes a hypothetical process for generating documents.

The generative process is:

  1. Choose the number of topics \(K\).

  2. For each topic, choose a distribution over words.

  3. For each document, choose a distribution over topics.

  4. For each word position in the document:

    • Choose a topic.

    • Choose a word from that topic.

The observed words are generated from the latent topic assignments.

3.3.7. Notation¶

Let:

  • \(D\) = number of documents.

  • \(K\) = number of topics.

  • \(V\) = vocabulary size.

  • \(N_d\) = number of words in document \(d\).

  • \(w_{dn}\) = observed word at position \(n\) in document \(d\).

  • \(z_{dn}\) = topic assignment for word \(n\) in document \(d\).

  • \(\theta_d\) = topic distribution for document \(d\).

  • \(\phi_k\) = word distribution for topic \(k\).

  • \(\alpha\) = Dirichlet prior parameter for document-topic distributions.

  • \(\beta\) = Dirichlet prior parameter for topic-word distributions.

The two main latent variables are:

(3.3.5)¶\[\theta_d\]

and

(3.3.6)¶\[\phi_k\]

where:

(3.3.7)¶\[\theta_d \sim \mathrm{Dirichlet}(\alpha)\]

and

(3.3.8)¶\[\phi_k \sim \mathrm{Dirichlet}(\beta)\]

3.3.8. Document-Topic Distribution¶

For each document \(d\), LDA assumes a topic distribution:

(3.3.9)¶\[\theta_d \sim \mathrm{Dirichlet}(\alpha)\]

The vector \(\theta_d\) contains the probability of each topic in the document.

For example, with three topics:

(3.3.10)¶\[\begin{split}\theta_d = \begin{bmatrix} 0.6 \\ 0.3 \\ 0.1 \end{bmatrix}\end{split}\]

This means:

  • Topic 1: 60%

  • Topic 2: 30%

  • Topic 3: 10%

The probabilities sum to one:

(3.3.11)¶\[\sum_{k=1}^{K}\theta_{dk}=1\]

3.3.9. Topic-Word Distribution¶

For every topic \(k\), LDA defines a probability distribution over the vocabulary:

(3.3.12)¶\[\phi_k \sim \mathrm{Dirichlet}(\beta)\]

For example:

(3.3.13)¶\[\begin{split}\phi_k = \begin{bmatrix} 0.05 \\ 0.15 \\ 0.10 \\ 0.20 \\ \vdots \end{bmatrix}\end{split}\]

Each element represents the probability of a particular word given the topic.

Therefore:

(3.3.14)¶\[\sum_{v=1}^{V}\phi_{kv}=1\]

3.3.10. Generative Process in Detail¶

The LDA generative process can be written as follows.

For each topic \(k\):

(3.3.15)¶\[\phi_k \sim \mathrm{Dirichlet}(\beta)\]

For each document \(d\):

(3.3.16)¶\[\theta_d \sim \mathrm{Dirichlet}(\alpha)\]

For each word position \(n\):

  1. Choose a topic:

(3.3.17)¶\[z_{dn} \sim \mathrm{Categorical}(\theta_d)\]

  1. Choose a word:

(3.3.18)¶\[w_{dn} \sim \mathrm{Categorical}(\phi_{z_{dn}})\]

Therefore:

(3.3.19)¶\[P(w_{dn}\mid z_{dn},\phi) = \phi_{z_{dn},w_{dn}}\]
