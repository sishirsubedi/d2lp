3.8.2. LDA¶

Probabilistic Latent Semantic Analysis (PLSA) and Latent Dirichlet Allocation (LDA) are both probabilistic models used for topic modeling, which is a method to discover abstract topics in a collection of documents. LDA is considered an improvement over PLSA in several significant ways. Here’s a comparison of the two and an explanation of the improvements introduced by LDA:

3.8.2.1. 1. Generative Process¶

  • PLSA: PLSA models each document as a mixture of topics, but it does not have a generative process for documents. The mixture weights are learned directly from the training data, meaning the model does not naturally generalize to new, unseen documents. Specifically, PLSA does not define a probability distribution over the topic mixtures for the entire collection, making it challenging to predict for new documents.

  • LDA: LDA introduces a generative process, where each document is assumed to be generated by first choosing a distribution over topics (drawn from a Dirichlet distribution), and then each word in the document is generated by first choosing a topic (according to the document’s distribution over topics) and then choosing a word (according to the topic’s distribution over words). This process allows LDA to define a complete generative model, including priors, making it possible to generalize to new documents.

3.8.2.2. 2. Handling New Documents¶

  • PLSA: The model parameters include a topic distribution for each document in the training set, but it does not provide a mechanism for assigning topics to new, unseen documents because it lacks a prior distribution over topics.

  • LDA: LDA addresses this limitation by using Dirichlet priors for the distribution of topics over documents and words over topics. This allows LDA to infer the topic distribution for new documents using Bayesian inference, making it capable of handling new, unseen documents.

3.8.2.3. 3. Parameter Estimation and Regularization¶

  • PLSA: PLSA is prone to overfitting because it lacks a prior distribution, and the parameters are estimated directly from the data without regularization. This can be problematic, especially with small datasets.

  • LDA: LDA incorporates Dirichlet priors, which act as regularizers. The Dirichlet prior helps prevent overfitting by smoothing the distribution of topics over documents and words over topics. This regularization effect makes LDA more robust and capable of providing more coherent topics, especially with limited data.

3.8.2.4. 4. Interpretability and Coherence of Topics¶

  • PLSA: Topics generated by PLSA may not always be as coherent or interpretable because the model is more prone to overfitting and does not include a mechanism for encouraging sparsity in the topic distributions.

  • LDA: The use of Dirichlet priors in LDA encourages sparsity in the topic distributions, leading to more interpretable and coherent topics. This sparsity implies that each document is typically associated with a small number of topics, and each topic is characterized by a small number of words with high probabilities, making the results more interpretable.

In Latent Dirichlet Allocation (LDA), the estimation of the parameters ( p(w|z) ) (the probability of word ( w ) given topic ( z )) and ( p(z|d) ) (the probability of topic ( z ) given document ( d )) involves a generative process that includes priors and the use of inference algorithms. Here’s a breakdown of how these parameters are estimated in LDA:

3.8.2.5. 1. Generative Model¶

  • LDA’s Generative Process:

    1. For each topic ( z ), draw a distribution over words ( :raw-latex:`\phi`_z ) from a Dirichlet distribution with hyperparameter ( :raw-latex:`\beta `): ( :raw-latex:`phi`_z :raw-latex:`\sim `:raw-latex:`text{Dir}`(:raw-latex:`\beta`) ).

    2. For each document ( d ), draw a distribution over topics ( :raw-latex:`\theta`_d ) from a Dirichlet distribution with hyperparameter ( :raw-latex:`\alpha `): ( :raw-latex:`theta`_d :raw-latex:`\sim `:raw-latex:`text{Dir}`(:raw-latex:`\alpha`) ).

    3. For each word ( w ) in document ( d ):

      • Draw a topic ( z_{d,n} ) from the multinomial distribution ( :raw-latex:`\theta`_d ).

      • Draw a word ( w_{d,n} ) from the multinomial distribution ( :raw-latex:`\phi`{z{d,n}} ).

3.8.2.6. 2. Parameter Estimation¶

The parameters ( p(w|z) ) and ( p(z|d) ) correspond to the distributions ( :raw-latex:`\phi`_z ) and ( :raw-latex:`\theta`_d ), respectively.

3.8.2.6.1. **Estimating ( p(w|z) ) (Topic-Word Distribution ( :raw-latex:`\phi`_z )):**¶

  • After Inference (Variational Inference or Gibbs Sampling):

    • For each topic ( z ), the parameter ( :raw-latex:`\phi`_z ) represents the distribution over words. This is estimated from the posterior distributions obtained during inference.

    • Using Gibbs Sampling, for instance, the estimate of ( :raw-latex:`\phi`_z ) can be computed as: [ :raw-latex:`\phi`z = :raw-latex:`frac{n_{w,z} + beta}{sum_{w’} (n_{w’,z} + beta)}` ] where ( n{w,z} ) is the count of word ( w ) being assigned to topic ( z ) across the corpus, and ( :raw-latex:`beta `) is the hyperparameter of the Dirichlet prior.

  • Interpretation:

    • ( :raw-latex:`\phi`_z ) is a multinomial distribution over words for topic ( z ). The elements of ( :raw-latex:`\phi`_z ) give the probabilities of observing each word given the topic ( z ).

3.8.2.6.2. **Estimating ( p(z|d) ) (Document-Topic Distribution ( :raw-latex:`\theta`_d )):**¶

  • After Inference:

    • For each document ( d ), the parameter ( :raw-latex:`\theta`_d ) represents the distribution over topics. This is inferred using the document-specific posterior distributions.

    • Using Gibbs Sampling, for example, the estimate of ( :raw-latex:`\theta`_d ) can be computed as: [ :raw-latex:`\theta`d = :raw-latex:`frac{n_{z,d} + alpha}{sum_{z’} (n_{z’,d} + alpha)}` ] where ( n{z,d} ) is the count of words in document ( d ) being assigned to topic ( z ), and ( :raw-latex:`alpha `) is the hyperparameter of the Dirichlet prior.

  • Interpretation:

    • ( :raw-latex:`\theta`_d ) is a multinomial distribution over topics for document ( d ). The elements of ( :raw-latex:`\theta`_d ) give the probabilities of each topic being present in the document.

3.8.2.7. Summary¶

In LDA, unlike PLSA, the parameters ( p(w|z) ) and ( p(z|d) ) are not directly calculated from data counts alone but are inferred as part of a probabilistic model that includes prior distributions. This inference involves techniques like Variational Inference or Gibbs Sampling, and the use of Dirichlet priors ( :raw-latex:`\alpha `) and ( :raw-latex:`beta ) helps in regularizing these estimates and ensuring generalization to new documents. The resulting parameters ( :raw-latex:phi`_z ) and ( :raw-latex:`\theta`_d ) provide the probabilities of words given topics and topics given documents, respectively.

Latent Dirichlet Allocation (LDA) is an extension and improvement over Probabilistic Latent Semantic Analysis (PLSA) in several key ways. To understand these improvements in terms of formulas, we can compare their respective models and the mathematical implications:

3.8.2.8. 1. Model Definition and Generative Process¶

3.8.2.8.1. PLSA Model:¶

In PLSA, the generative model for a document ( d ) and word ( w ) involves the following:

  • Probability of a word given a topic ( z ): [ p(w|z) = :raw-latex:`\phi`{w|z} ] where ( :raw-latex:`phi`{w|z} ) represents the probability of word ( w ) given topic ( z ).

  • Probability of a topic given a document ( d ): [ p(z|d) = :raw-latex:`\theta`{z|d} ] where ( :raw-latex:`theta`{z|d} ) represents the probability of topic ( z ) given document ( d ).

  • Joint probability of a word and a document: [ p(d, w) = p(d) :raw-latex:`\sum`_{z} p(z|d)p(w|z) ]

PLSA does not define a prior distribution over (:raw-latex:`\theta`{z|d} ) and cannot naturally extend to new documents since (:raw-latex:`theta`{z|d} ) is only defined for documents in the training set.

3.8.2.8.2. LDA Model:¶

In LDA, the generative model introduces prior distributions over the parameters, making the model more robust and capable of generalization.

  • Dirichlet Prior for Document-Topic Distribution: [ :raw-latex:`\theta`_d :raw-latex:`\sim `:raw-latex:`text{Dir}`(:raw-latex:`\alpha`) ] where ( :raw-latex:`\theta`_d ) is the topic distribution for document ( d ), and ( :raw-latex:`alpha `) is the Dirichlet prior parameter.

  • Dirichlet Prior for Topic-Word Distribution: [ :raw-latex:`\phi`_z :raw-latex:`\sim `:raw-latex:`text{Dir}`(:raw-latex:`\beta`) ] where ( :raw-latex:`\phi`_z ) is the word distribution for topic ( z ), and ( :raw-latex:`beta `) is the Dirichlet prior parameter.

  • Probability of a word given a topic: [ p(w|z) = :raw-latex:`\phi`_{w|z} ]

  • Probability of a topic given a document: [ p(z|d) = :raw-latex:`\theta`_{z|d} ]

  • Joint probability of a word, topic, and document: [ p(d, w, z) = p(d)p(:raw-latex:`\theta`_d)p(z|:raw-latex:theta_d)p(w|z, :raw-latex:`\phi`_z) ]

3.8.2.9. 2. Formulaic Differences and Implications¶

3.8.2.9.1. Parameter Estimation and Regularization:¶

  • PLSA directly estimates ( :raw-latex:`\phi`{w|z} ) and ( :raw-latex:`theta`{z|d} ) from data without priors, which can lead to overfitting.

  • LDA uses Dirichlet priors ( :raw-latex:`\alpha `) and ( :raw-latex:`beta ) over ( :raw-latex:theta`_d ) and ( :raw-latex:`\phi`z ) respectively: [ p(:raw-latex:`theta`d|:raw-latex:`alpha`) = :raw-latex:`frac{Gamma(sum_{i=1}^K alpha_i)}{prod_{i=1}^K Gamma(alpha_i)}` :raw-latex:`prod`{i=1}^K :raw-latex:`theta`{d,i}{:raw-latex:alpha`i - 1} ] [ p(:raw-latex:`\phi`z|:raw-latex:beta) = :raw-latex:`\frac{\Gamma(\sum_{i=1}^V \beta_i)}{\prod_{i=1}^V \Gamma(\beta_i)}` :raw-latex:`\prod`{i=1}^V :raw-latex:`\phi`{z,i}`{:raw-latex:`\beta`_i - 1} ] These priors act as regularizers, preventing the model from overfitting and allowing it to generalize better to new data.

3.8.2.9.2. Inference and Generalization:¶

  • PLSA cannot easily handle new documents because it does not define a generative process for document-topic distributions.

  • LDA can infer the topic distribution ( :raw-latex:`\theta`_d ) for new documents using the posterior distribution: [ p(:raw-latex:`\theta`d | w_d, :raw-latex:`alpha`, :raw-latex:`beta`) :raw-latex:`propto `p(:raw-latex:`theta`d|:raw-latex:`alpha`) :raw-latex:`prod`{n=1}^{N_d} :raw-latex:`sum`{z=1}^K p(z|:raw-latex:theta_d) p(w_n|z, :raw-latex:`\beta`) ] This is possible because of the inclusion of the Dirichlet prior ( :raw-latex:`\alpha `) on the document-topic distribution ( :raw-latex:`theta`_d ), allowing LDA to extend to new, unseen documents.

3.8.2.10. Summary¶

In summary, LDA’s inclusion of Dirichlet priors ( :raw-latex:`\alpha `) and ( :raw-latex:`beta `) provides a more principled framework, enabling better regularization and generalization compared to PLSA. The explicit modeling of these priors allows LDA to infer the distribution of topics for new documents, overcoming a key limitation of PLSA. This leads to more robust and interpretable models, especially when dealing with sparse data or the need for generalization.

I’ll provide an overview of simple implementations for PLSA and variational inference for LDA using Python. These implementations are meant for educational purposes and do not include all optimizations or robustness checks.

3.8.2.11. 1. Model Complexity¶

  • PLSA: PLSA has a simpler model structure without priors on the topic distributions. The EM algorithm used in PLSA involves calculating posterior probabilities (p(z|d,w)) and updating the model parameters (p(w|z) and p(z|d)). The absence of a prior means fewer parameters and simpler updates.

  • LDA: LDA introduces Dirichlet priors for both the document-topic distribution (θ_d) and the topic-word distribution (φ_z). The inference process in LDA, such as Variational Inference or Gibbs Sampling, requires iterative updates of the variational parameters (γ_d, φ_dw) or topic assignments for each word. The additional complexity of handling priors and performing more intricate updates can make LDA computationally more intensive.

3.8.2.12. 2. Inference Algorithm¶

  • PLSA: The EM algorithm used in PLSA generally has straightforward updates that converge relatively quickly. However, PLSA can suffer from overfitting and lacks a probabilistic generative process for new documents.

  • LDA: Variational Inference in LDA involves optimizing variational parameters, which can be computationally expensive due to the need for calculating digamma functions and ensuring convergence of the variational lower bound. Gibbs Sampling, another common inference method for LDA, involves iteratively sampling topic assignments for each word, which can be slow for large datasets.

3.8.2.13. 3. Convergence and Scalability¶

  • PLSA: Convergence criteria in PLSA are typically based on changes in the likelihood function. PLSA may converge faster due to fewer parameters being updated.

  • LDA: Convergence criteria in LDA involve the variational lower bound or changes in the distribution of the latent variables. The presence of priors and the need to maintain a coherent generative model can result in slower convergence, particularly for large datasets with many documents and words.

3.8.2.14. Summary¶

While LDA generally provides a more robust and principled approach to topic modeling, especially for handling new documents and providing interpretable topics, it can be computationally slower than PLSA due to the complexity of the model and the inference algorithms used. The specific implementation and optimization techniques can significantly impact the relative speed of both methods. For practical applications, it is crucial to consider these trade-offs and possibly use efficient implementations or approximations to balance accuracy and computational efficiency.
