2.10.4. PCA vs. Factor Analysis¶
Open the notebook in Colab
Open the notebook in Colab
Open the notebook in Colab
Open the notebook in Colab

Factor analysis encompasses a variety of techniques used for uncovering the underlying factors or latent variables that explain the observed data. Each method makes different assumptions about the data and employs different statistical models. This chapter covers Probabilistic Principal Component Analysis (PPCA), Gaussian Matrix Factorization, and Poisson Matrix Factorization.

2.10.4.1. Probabilistic Principal Component Analysis (PPCA)¶

2.10.4.2. Overview¶

  • PPCA is a probabilistic approach to PCA that frames the dimensionality reduction problem in a probabilistic context.

  • It models the data as being generated by a set of latent variables with added Gaussian noise.

2.10.4.3. Model¶

The data \(\mathbf{x}_i\) is modeled as:

(2.10.229)¶\[\mathbf{x}_i = \mathbf{W}\mathbf{z}_i + \boldsymbol{\mu} + \boldsymbol{\epsilon}_i\]

where:

  • \(\mathbf{x}_i\) is the observed data.

  • \(\mathbf{W}\) is the factor loading matrix.

  • \(\mathbf{z}_i\) is the latent variable or factor.

  • \(\boldsymbol{\mu}\) is the mean vector.

  • \(\boldsymbol{\epsilon}_i\) is Gaussian noise with covariance \(\sigma^2\mathbf{I}\).

2.10.4.4. Characteristics¶

  • Latent Variables: The latent variables are modeled as \(\mathbf{z}_i \sim \mathcal{N}(0,\mathbf{I})\).

  • Maximum Likelihood: Parameters \(\mathbf{W}\) and \(\sigma^2\) are estimated using maximum likelihood.

  • Principal Components: The principal components in PCA correspond to the maximum-likelihood solution in PPCA.

2.10.4.5. Gaussian Matrix Factorization¶

2.10.4.6. Overview¶

Gaussian Matrix Factorization is used to decompose a matrix into lower-dimensional latent factors under the assumption of Gaussian noise. It is commonly used in collaborative filtering and recommendation systems.

2.10.4.7. Model¶

The data matrix \(\mathbf{X}\) is decomposed into two lower-dimensional matrices:

(2.10.230)¶\[\mathbf{X} \approx \mathbf{U}\mathbf{V}^T\]

where:

  • \(\mathbf{U} \in \mathbb{R}^{n \times k}\) is the matrix of latent factors for rows.

  • \(\mathbf{V} \in \mathbb{R}^{m \times k}\) is the matrix of latent factors for columns.

  • \(k\) is the number of latent factors.

The entries of \(\mathbf{X}\) are assumed to be Gaussian-distributed around \(\mathbf{U}\mathbf{V}^T\).

2.10.4.8. Characteristics¶

  • Gaussian Noise: The model assumes Gaussian noise in the observed data.

  • Latent Factors: It captures latent factors that explain the observed data.

  • Optimization: It can be solved using alternating least squares or stochastic gradient descent.

2.10.4.9. Poisson Matrix Factorization¶

2.10.4.10. Overview¶

Poisson Matrix Factorization is used for decomposing count data into latent factors. It is commonly used for applications such as topic modeling and collaborative filtering with count data.

2.10.4.11. Model¶

The data matrix \(\mathbf{X}\) is assumed to follow a Poisson distribution:

(2.10.231)¶\[X_{ij} \sim \operatorname{Poisson}\left((\mathbf{U}\mathbf{V}^T)_{ij}\right)\]

where:

  • \(\mathbf{U} \in \mathbb{R}^{n \times k}\) is a non-negative latent factor matrix.

  • \(\mathbf{V} \in \mathbb{R}^{m \times k}\) is a non-negative latent factor matrix.

  • \((\mathbf{U}\mathbf{V}^T)_{ij}\) is the expected rate parameter of the Poisson distribution.

2.10.4.12. Characteristics¶

  • Poisson Noise: The observed counts are assumed to follow a Poisson distribution.

  • Non-Negativity: The latent factors \(\mathbf{U}\) and \(\mathbf{V}\) are non-negative.

  • Optimization: Parameters can be estimated using maximum likelihood or Bayesian inference.

2.10.4.14. Summary¶

  • PPCA: Extends PCA into a probabilistic framework and captures linear relationships with Gaussian noise.

  • Gaussian Matrix Factorization: Decomposes a data matrix into latent factors assuming Gaussian-distributed errors. It is commonly used in recommendation systems.

  • Poisson Matrix Factorization: Is designed for count data and decomposes the data matrix into non-negative latent factors using a Poisson distribution.

Each method is suited to different types of data and underlying assumptions.

2.10.4.15. Gaussian Matrix Factorization¶

Gaussian Matrix Factorization is a commonly used technique for collaborative filtering, particularly in recommendation systems. The goal is to factorize a matrix, usually containing user-item ratings, into two lower-dimensional matrices representing latent factors for users and items.

The model assumes that the observed entries are noisy observations from a Gaussian distribution.

2.10.4.16. Model Formulation¶

Given an observed data matrix:

(2.10.232)¶\[R \in \mathbb{R}^{n \times m}\]

where:

  • \(n\) is the number of users.

  • \(m\) is the number of items.

The goal is to approximate \(R\) using two lower-dimensional matrices:

(2.10.233)¶\[R \approx UV^T\]

where:

  • \(U \in \mathbb{R}^{n \times k}\) is the user latent factor matrix.

  • \(V \in \mathbb{R}^{m \times k}\) is the item latent factor matrix.

  • \(k\) is the number of latent factors.

The entries of \(R\) are assumed to be Gaussian-distributed around \(UV^T\).

2.10.4.17. Objective Function¶

The objective is to minimize the squared difference between observed and predicted entries while using regularization to prevent overfitting:

(2.10.234)¶\[\min_{U,V} \sum_{(i,j)\in\mathcal{O}} (R_{ij}-U_iV_j^T)^2 + \lambda \left( \|U\|_F^2+\|V\|_F^2 \right)\]

where:

  • \(\mathcal{O}\) is the set of observed entries.

  • \(\lambda\) is the regularization parameter.

  • \(\|U\|_F^2\) and \(\|V\|_F^2\) are Frobenius norms.

2.10.4.18. Solving Using Alternating Least Squares¶

Alternating Least Squares (ALS) is an iterative optimization technique in which one matrix is fixed while the other is optimized.

2.10.4.19. Step 1: Initialize¶

Initialize \(U\) and \(V\) with random values or another suitable initialization strategy.

2.10.4.20. Step 2: Optimize \(U\) Given \(V\)¶

For each user \(i\), solve:

(2.10.235)¶\[U_i = \left( \sum_{j\in\mathcal{O}_i} V_jV_j^T + \lambda I \right)^{-1} \left( \sum_{j\in\mathcal{O}_i} R_{ij}V_j \right)\]

where \(\mathcal{O}_i\) is the set of items rated by user \(i\).

2.10.4.21. Step 3: Optimize \(V\) Given \(U\)¶

For each item \(j\), solve:

(2.10.236)¶\[V_j = \left( \sum_{i\in\mathcal{O}_j} U_iU_i^T + \lambda I \right)^{-1} \left( \sum_{i\in\mathcal{O}_j} R_{ij}U_i \right)\]

where \(\mathcal{O}_j\) is the set of users who rated item \(j\).

2.10.4.22. Step 4: Iterate¶

Repeat the updates of \(U\) and \(V\) until convergence.

A common convergence criterion is that the change in the objective function, \(U\), and \(V\) becomes smaller than a predefined threshold.

2.10.4.23. Gaussian Matrix Factorization in a Probabilistic Context¶

2.10.4.24. Probabilistic Model¶

In probabilistic Gaussian Matrix Factorization, the observed matrix \(R\) is assumed to be generated by a probabilistic process involving latent variables for users and items.

2.10.4.25. Model Assumptions¶

2.10.4.25.1. 1. Latent Factors¶

Each user \(i\) is associated with a latent vector:

(2.10.237)¶\[\mathbf{u}_i \in \mathbb{R}^k\]

Each item \(j\) is associated with a latent vector:

(2.10.238)¶\[\mathbf{v}_j \in \mathbb{R}^k\]

2.10.4.25.2. 2. Observed Ratings¶

The observed rating \(R_{ij}\) is modeled as:

(2.10.239)¶\[R_{ij} \sim \mathcal{N} \left( \mathbf{u}_i^T\mathbf{v}_j, \sigma^2 \right)\]

2.10.4.25.3. 3. Priors on Latent Factors¶

The latent factors are assigned Gaussian priors:

(2.10.240)¶\[\mathbf{u}_i \sim \mathcal{N} \left( \mathbf{0}, \lambda_u^{-1}I \right)\]

and

(2.10.241)¶\[\mathbf{v}_j \sim \mathcal{N} \left( \mathbf{0}, \lambda_v^{-1}I \right)\]

Here, \(\lambda_u\) and \(\lambda_v\) are precision parameters, which are the inverse of variance.

2.10.4.26. Probabilistic Formulation¶

The likelihood of the observed data is:

(2.10.242)¶\[p(R\mid U,V,\sigma^2) = \prod_{(i,j)\in\mathcal{O}} \mathcal{N} \left( R_{ij} \mid \mathbf{u}_i^T\mathbf{v}_j, \sigma^2 \right)\]

The prior distributions are:

(2.10.243)¶\[p(U\mid\lambda_u) = \prod_{i=1}^{n} \mathcal{N} \left( \mathbf{u}_i \mid \mathbf{0}, \lambda_u^{-1}I \right)\]

and

(2.10.244)¶\[p(V\mid\lambda_v) = \prod_{j=1}^{m} \mathcal{N} \left( \mathbf{v}_j \mid \mathbf{0}, \lambda_v^{-1}I \right)\]

2.10.4.27. Posterior Distribution¶

The posterior distribution is proportional to the product of the likelihood and the priors:

(2.10.245)¶\[p(U,V\mid R,\sigma^2,\lambda_u,\lambda_v) \propto p(R\mid U,V,\sigma^2) p(U\mid\lambda_u) p(V\mid\lambda_v)\]

2.10.4.28. Maximizing the Posterior¶

Maximizing the posterior is equivalent to minimizing the negative log-posterior:

(2.10.246)¶\[\mathcal{L} = \sum_{(i,j)\in\mathcal{O}} \frac{ (R_{ij}-\mathbf{u}_i^T\mathbf{v}_j)^2 }{ 2\sigma^2 } + \frac{\lambda_u}{2} \sum_{i=1}^{n} \|\mathbf{u}_i\|^2 + \frac{\lambda_v}{2} \sum_{j=1}^{m} \|\mathbf{v}_j\|^2\]

The update for \(\mathbf{u}_i\) is:

(2.10.247)¶\[\mathbf{u}_i = \left( \sum_{j\in\mathcal{O}_i} \mathbf{v}_j\mathbf{v}_j^T + \lambda_u\sigma^2I \right)^{-1} \left( \sum_{j\in\mathcal{O}_i} R_{ij}\mathbf{v}_j \right)\]

Similarly, the update for \(\mathbf{v}_j\) is:

(2.10.248)¶\[\mathbf{v}_j = \left( \sum_{i\in\mathcal{O}_j} \mathbf{u}_i\mathbf{u}_i^T + \lambda_v\sigma^2I \right)^{-1} \left( \sum_{i\in\mathcal{O}_j} R_{ij}\mathbf{u}_i \right)\]

2.10.4.29. Log-Likelihood¶

Taking the logarithm of the likelihood:

(2.10.249)¶\[\log p(R\mid U,V,\sigma^2) = -\frac{1}{2\sigma^2} \sum_{(i,j)\in\mathcal{O}} (R_{ij}-\mathbf{u}_i^T\mathbf{v}_j)^2 - \frac{|\mathcal{O}|}{2} \log(2\pi\sigma^2)\]

2.10.4.30. Priors¶

The priors on the latent factors are:

(2.10.250)¶\[p(\mathbf{u}_i) = \mathcal{N} \left( \mathbf{u}_i \mid \mathbf{0}, \lambda_u^{-1}I \right)\]

and

(2.10.251)¶\[p(\mathbf{v}_j) = \mathcal{N} \left( \mathbf{v}_j \mid \mathbf{0}, \lambda_v^{-1}I \right)\]

Taking the logarithm:

(2.10.252)¶\[\log p(\mathbf{u}_i) = -\frac{\lambda_u}{2} \|\mathbf{u}_i\|^2 - \frac{k}{2} \log(2\pi\lambda_u^{-1})\]

and

(2.10.253)¶\[\log p(\mathbf{v}_j) = -\frac{\lambda_v}{2} \|\mathbf{v}_j\|^2 - \frac{k}{2} \log(2\pi\lambda_v^{-1})\]

2.10.4.31. Posterior¶

The log posterior is:

(2.10.254)¶\[\log p(U,V\mid R,\sigma^2,\lambda_u,\lambda_v) = \log p(R\mid U,V,\sigma^2) + \sum_i\log p(\mathbf{u}_i) + \sum_j\log p(\mathbf{v}_j)\]

2.10.4.32. Maximum A Posteriori Estimation¶

The MAP objective is:

(2.10.255)¶\[\mathcal{L} = \frac{1}{2\sigma^2} \sum_{(i,j)\in\mathcal{O}} (R_{ij}-\mathbf{u}_i^T\mathbf{v}_j)^2 + \frac{\lambda_u}{2} \sum_{i=1}^{n} \|\mathbf{u}_i\|^2 + \frac{\lambda_v}{2} \sum_{j=1}^{m} \|\mathbf{v}_j\|^2\]

Taking the partial derivative with respect to \(\mathbf{u}_i\):

(2.10.256)¶\[\frac{\partial\mathcal{L}} {\partial\mathbf{u}_i} = -\frac{1}{\sigma^2} \sum_{j\in\mathcal{O}_i} (R_{ij}-\mathbf{u}_i^T\mathbf{v}_j)\mathbf{v}_j + \lambda_u\mathbf{u}_i\]

Setting the derivative to zero:

(2.10.257)¶\[\sum_{j\in\mathcal{O}_i} (R_{ij}-\mathbf{u}_i^T\mathbf{v}_j) \mathbf{v}_j = \sigma^2\lambda_u\mathbf{u}_i\]

Rearranging:

(2.10.258)¶\[\sum_{j\in\mathcal{O}_i} R_{ij}\mathbf{v}_j = \left( \sum_{j\in\mathcal{O}_i} \mathbf{v}_j\mathbf{v}_j^T + \sigma^2\lambda_uI \right) \mathbf{u}_i\]

Therefore:

(2.10.259)¶\[\boxed{ \mathbf{u}_i = \left( \sum_{j\in\mathcal{O}_i} \mathbf{v}_j\mathbf{v}_j^T + \sigma^2\lambda_uI \right)^{-1} \left( \sum_{j\in\mathcal{O}_i} R_{ij}\mathbf{v}_j \right) }\]

This is the MAP update equation for \(\mathbf{u}_i\).

2.10.4.33. Non-Negativity in Gaussian Matrix Factorization¶

Non-negativity is not normally enforced in Gaussian Matrix Factorization. GMF does not inherently require latent factors to be non-negative.

However, non-negativity may be useful when latent factors need to be interpretable or when the application requires positive components.

One common alternative is Non-Negative Matrix Factorization (NMF), which explicitly constrains the latent factors to be non-negative.

Another option is to enforce non-negativity directly during optimization using projected gradient descent.

2.10.4.34. Projected Gradient Descent¶

After a gradient update, project each element onto the non-negative domain.

For \(U\):

(2.10.260)¶\[\mathbf{u}_i \leftarrow \mathbf{u}_i - \eta \frac{\partial\mathcal{L}} {\partial\mathbf{u}_i}\]

Then:

(2.10.261)¶\[\mathbf{u}_i \leftarrow \max(\mathbf{u}_i,0)\]

Similarly, for \(V\):

(2.10.262)¶\[\mathbf{v}_j \leftarrow \mathbf{v}_j - \eta \frac{\partial\mathcal{L}} {\partial\mathbf{v}_j}\]

Then:

(2.10.263)¶\[\mathbf{v}_j \leftarrow \max(\mathbf{v}_j,0)\]

where \(\eta\) is the learning rate.

2.10.4.35. Poisson Matrix Factorization¶

Poisson Matrix Factorization (PMF) is used for decomposing count data into latent factors. The observed entries are assumed to follow a Poisson distribution, and the latent factors are non-negative.

2.10.4.36. Probabilistic Model¶

Given an observed count matrix \(R\), we approximate it using:

(2.10.264)¶\[R \approx UV^T\]

The model assumes:

(2.10.265)¶\[R_{ij} \sim \operatorname{Poisson} \left( (UV^T)_{ij} \right)\]

The latent factors satisfy:

(2.10.266)¶\[\mathbf{u}_i \geq 0\]

and

(2.10.267)¶\[\mathbf{v}_j \geq 0\]

2.10.4.37. Objective Function¶

The Poisson log-likelihood is:

(2.10.268)¶\[\log p(R\mid U,V) = \sum_{(i,j)\in\mathcal{O}} \left[ R_{ij} \log((UV^T)_{ij}) - (UV^T)_{ij} \right] - \sum_{(i,j)\in\mathcal{O}} \log(R_{ij}!)\]

2.10.4.38. Multiplicative Updates¶

For fixed \(V\), the update for \(U\) is:

(2.10.269)¶\[U_{ik} \leftarrow U_{ik} \frac{ \sum_j R_{ij} \frac{V_{jk}}{(UV^T)_{ij}} }{ \sum_j V_{jk} }\]

For fixed \(U\), the update for \(V\) is:

(2.10.270)¶\[V_{jk} \leftarrow V_{jk} \frac{ \sum_i R_{ij} \frac{U_{ik}}{(UV^T)_{ij}} }{ \sum_i U_{ik} }\]

These multiplicative updates preserve non-negativity provided that \(U\) and \(V\) are initialized with non-negative values.

2.10.4.39. Derivation of the Poisson Matrix Factorization Update¶

2.10.4.39.1. Probabilistic Model¶

The observed counts are modeled as:

(2.10.271)¶\[R_{ij} \sim \operatorname{Poisson} (\lambda_{ij})\]

where:

(2.10.272)¶\[\lambda_{ij} = \mathbf{u}_i^T\mathbf{v}_j\]

2.10.4.39.2. Log-Likelihood¶

The likelihood is:

(2.10.273)¶\[p(R\mid U,V) = \prod_{(i,j)\in\mathcal{O}} \operatorname{Poisson} (R_{ij}\mid\mathbf{u}_i^T\mathbf{v}_j)\]

The Poisson probability mass function is:

(2.10.274)¶\[\operatorname{Poisson}(R_{ij}\mid\lambda_{ij}) = \frac{ \lambda_{ij}^{R_{ij}} e^{-\lambda_{ij}} }{ R_{ij}! }\]

Therefore:

(2.10.275)¶\[\log p(R\mid U,V) = \sum_{(i,j)\in\mathcal{O}} \left[ R_{ij} \log(\mathbf{u}_i^T\mathbf{v}_j) - \mathbf{u}_i^T\mathbf{v}_j - \log(R_{ij}!) \right]\]

2.10.4.39.3. Gradient with Respect to \(\mathbf{u}_i\)¶

The factorial term is constant with respect to \(\mathbf{u}_i\), so it can be ignored during differentiation.

We obtain:

(2.10.276)¶\[\frac{ \partial\log p(R\mid U,V) }{ \partial\mathbf{u}_i } = \sum_{j\in\mathcal{O}_i} \left[ R_{ij} \frac{\mathbf{v}_j} {\mathbf{u}_i^T\mathbf{v}_j} - \mathbf{v}_j \right]\]

or equivalently:

(2.10.277)¶\[\frac{ \partial\log p(R\mid U,V) }{ \partial\mathbf{u}_i } = \sum_{j\in\mathcal{O}_i} \left[ \frac{R_{ij}\mathbf{v}_j} {\mathbf{u}_i^T\mathbf{v}_j} - \mathbf{v}_j \right]\]

2.10.4.39.4. Multiplicative Update¶

Setting the gradient to zero gives:

(2.10.278)¶\[\sum_{j\in\mathcal{O}_i} \frac{R_{ij}\mathbf{v}_j} {\mathbf{u}_i^T\mathbf{v}_j} = \sum_{j\in\mathcal{O}_i} \mathbf{v}_j\]

The multiplicative update is:

(2.10.279)¶\[\boxed{ \mathbf{u}_i \leftarrow \mathbf{u}_i \circ \frac{ \sum_{j\in\mathcal{O}_i} R_{ij} \frac{\mathbf{v}_j} {\mathbf{u}_i^T\mathbf{v}_j} }{ \sum_{j\in\mathcal{O}_i} \mathbf{v}_j } }\]

where \(\circ\) denotes element-wise multiplication.

2.10.4.39.5. Poisson Matrix Factorization with Gamma Priors¶

Gamma priors are commonly used for non-negative latent factors and can encourage sparsity.

2.10.4.40. Probabilistic Model¶

The observed counts are:

(2.10.280)¶\[R_{ij} \sim \operatorname{Poisson} (\mathbf{u}_i^T\mathbf{v}_j)\]

The latent factors have Gamma priors:

(2.10.281)¶\[u_{ik} \sim \operatorname{Gamma} (\alpha_u,\beta_u)\]

and:

(2.10.282)¶\[v_{jk} \sim \operatorname{Gamma} (\alpha_v,\beta_v)\]

The Gamma density is:

(2.10.283)¶\[\operatorname{Gamma}(x\mid\alpha,\beta) = \frac{ \beta^\alpha x^{\alpha-1} e^{-\beta x} }{ \Gamma(\alpha) }\]

where \(\alpha\) is the shape parameter and \(\beta\) is the rate parameter.

2.10.4.41. Joint Log-Likelihood¶

Ignoring constants independent of \(U\) and \(V\):

(2.10.284)¶\[\log p(R,U,V) = \sum_{(i,j)\in\mathcal{O}} \left[ R_{ij} \log(\mathbf{u}_i^T\mathbf{v}_j) - \mathbf{u}_i^T\mathbf{v}_j \right]\]
(2.10.285)¶\[+ \sum_{i,k} \left[ (\alpha_u-1)\log u_{ik} - \beta_u u_{ik} \right]\]
(2.10.286)¶\[+ \sum_{j,k} \left[ (\alpha_v-1)\log v_{jk} - \beta_v v_{jk} \right]\]

2.10.4.42. Gradient with Respect to \(u_{ik}\)¶

The derivative is:

(2.10.287)¶\[\frac{ \partial\log p(R,U,V) }{ \partial u_{ik} } = \sum_{j\in\mathcal{O}_i} \left[ R_{ij} \frac{v_{jk}} {\mathbf{u}_i^T\mathbf{v}_j} - v_{jk} \right] + \frac{\alpha_u-1}{u_{ik}} - \beta_u\]

Similarly, for \(v_{jk}\):

(2.10.288)¶\[\frac{ \partial\log p(R,U,V) }{ \partial v_{jk} } = \sum_{i\in\mathcal{O}_j} \left[ R_{ij} \frac{u_{ik}} {\mathbf{u}_i^T\mathbf{v}_j} - u_{ik} \right] + \frac{\alpha_v-1}{v_{jk}} - \beta_v\]

2.10.4.43. Multiplicative Updates with Gamma Priors¶

A commonly used multiplicative update form for \(U\) is:

(2.10.289)¶\[u_{ik} \leftarrow u_{ik} \frac{ \displaystyle \sum_{j\in\mathcal{O}_i} R_{ij} \frac{v_{jk}} {\mathbf{u}_i^T\mathbf{v}_j} + \alpha_u-1 }{ \displaystyle \sum_{j\in\mathcal{O}_i} v_{jk} + \beta_u }\]

Similarly, for \(V\):

(2.10.290)¶\[v_{jk} \leftarrow v_{jk} \frac{ \displaystyle \sum_{i\in\mathcal{O}_j} R_{ij} \frac{u_{ik}} {\mathbf{u}_i^T\mathbf{v}_j} + \alpha_v-1 }{ \displaystyle \sum_{i\in\mathcal{O}_j} u_{ik} + \beta_v }\]

These updates preserve non-negativity when initialized with positive values.

Note: The exact multiplicative-update form depends on the optimization derivation and parameterization of the Gamma prior. The equations above correspond to a common gradient-based construction. A fully Bayesian treatment instead uses variational inference or Gibbs sampling.

2.10.4.44. Poisson Matrix Factorization with Gamma Priors and ELBO¶

A more principled Bayesian approach to Poisson Matrix Factorization with Gamma priors uses variational inference.

2.10.4.45. Variational Inference with Auxiliary Variables¶

Variational inference approximates the true posterior with a simpler distribution that can be optimized efficiently.

The model is:

(2.10.291)¶\[R_{ij} \sim \operatorname{Poisson} (\mathbf{u}_i^T\mathbf{v}_j)\]

with priors:

(2.10.292)¶\[u_{ik} \sim \operatorname{Gamma} (\alpha_u,\beta_u)\]

and:

(2.10.293)¶\[v_{jk} \sim \operatorname{Gamma} (\alpha_v,\beta_v)\]

2.10.4.46. Variational Distribution¶

We use a mean-field approximation:

(2.10.294)¶\[q(U,V) = \prod_{i,k} q(u_{ik}) \prod_{j,k} q(v_{jk})\]

where:

(2.10.295)¶\[q(u_{ik}) = \operatorname{Gamma} ( \tilde{\alpha}_{u_{ik}}, \tilde{\beta}_{u_{ik}} )\]

and:

(2.10.296)¶\[q(v_{jk}) = \operatorname{Gamma} ( \tilde{\alpha}_{v_{jk}}, \tilde{\beta}_{v_{jk}} )\]

The variational parameters are:

  • \(\tilde{\alpha}\): variational shape parameter.

  • \(\tilde{\beta}\): variational rate parameter.

2.10.4.47. Evidence Lower Bound¶

The Evidence Lower Bound (ELBO) is:

(2.10.297)¶\[\operatorname{ELBO} = \mathbb{E}_q [ \log p(R,U,V) ] - \mathbb{E}_q [ \log q(U,V) ]\]

Maximizing the ELBO makes the variational approximation closer to the true posterior.

2.10.4.48. Expected Log-Likelihood¶

The expected log-likelihood is:

(2.10.298)¶\[\mathbb{E}_q [ \log p(R\mid U,V) ] = \sum_{(i,j)\in\mathcal{O}} \mathbb{E}_q \left[ R_{ij} \log(\mathbf{u}_i^T\mathbf{v}_j) - \mathbf{u}_i^T\mathbf{v}_j \right] + \text{const}\]

The expectation of the rate parameter is:

(2.10.299)¶\[\mathbb{E}_q [ \mathbf{u}_i^T\mathbf{v}_j ] = \sum_k \mathbb{E}_q[u_{ik}] \mathbb{E}_q[v_{jk}]\]

For a Gamma random variable:

(2.10.300)¶\[\mathbb{E}[u_{ik}] = \frac{ \tilde{\alpha}_{u_{ik}} }{ \tilde{\beta}_{u_{ik}} }\]

and:

(2.10.301)¶\[\mathbb{E}[v_{jk}] = \frac{ \tilde{\alpha}_{v_{jk}} }{ \tilde{\beta}_{v_{jk}} }\]

Therefore:

(2.10.302)¶\[\mathbb{E}_q [ \mathbf{u}_i^T\mathbf{v}_j ] = \sum_k \frac{ \tilde{\alpha}_{u_{ik}} }{ \tilde{\beta}_{u_{ik}} } \frac{ \tilde{\alpha}_{v_{jk}} }{ \tilde{\beta}_{v_{jk}} }\]

2.10.4.49. Prior Term¶

For \(U\):

(2.10.303)¶\[\mathbb{E}_q[\log p(U)] = \sum_{i,k} \left[ (\alpha_u-1) \mathbb{E}_q[\log u_{ik}] - \beta_u \mathbb{E}_q[u_{ik}] \right] + \text{const}\]

For a Gamma distribution:

(2.10.304)¶\[\mathbb{E}_q[\log u_{ik}] = \psi( \tilde{\alpha}_{u_{ik}} ) - \log \tilde{\beta}_{u_{ik}}\]

and:

(2.10.305)¶\[\mathbb{E}_q[u_{ik}] = \frac{ \tilde{\alpha}_{u_{ik}} }{ \tilde{\beta}_{u_{ik}} }\]

Therefore:

(2.10.306)¶\[\mathbb{E}_q[\log p(U)] = \sum_{i,k} \left[ (\alpha_u-1) \left( \psi(\tilde{\alpha}_{u_{ik}}) - \log\tilde{\beta}_{u_{ik}} \right) - \beta_u \frac{ \tilde{\alpha}_{u_{ik}} }{ \tilde{\beta}_{u_{ik}} } \right] + \text{const}\]

A corresponding expression applies to \(V\).

2.10.4.50. Entropy Term¶

The entropy contribution can be written through:

(2.10.307)¶\[-\mathbb{E}_q[\log q(U)]\]

and:

(2.10.308)¶\[-\mathbb{E}_q[\log q(V)]\]

For the Gamma variational distribution:

(2.10.309)¶\[\mathbb{E}_q[\log u_{ik}] = \psi( \tilde{\alpha}_{u_{ik}} ) - \log \tilde{\beta}_{u_{ik}}\]

and:

(2.10.310)¶\[\mathbb{E}_q[u_{ik}] = \frac{ \tilde{\alpha}_{u_{ik}} }{ \tilde{\beta}_{u_{ik}} }\]

These quantities are used to evaluate the ELBO.

2.10.4.51. Variational Updates¶

The variational parameters are updated iteratively.

A useful quantity for the expected contribution of component \(k\) to observation \((i,j)\) is:

(2.10.311)¶\[\phi_{ijk} = \frac{ \mathbb{E}_q[u_{ik}] \mathbb{E}_q[v_{jk}] }{ \sum_{\ell} \mathbb{E}_q[u_{i\ell}] \mathbb{E}_q[v_{j\ell}] }\]

where:

(2.10.312)¶\[\sum_k \phi_{ijk}=1\]

The expected number of observations assigned to component \(k\) is:

(2.10.313)¶\[\hat{R}_{ijk} = R_{ij}\phi_{ijk}\]

2.10.4.52. Update for \(u_{ik}\)¶

The variational shape parameter becomes:

(2.10.314)¶\[\tilde{\alpha}_{u_{ik}} = \alpha_u + \sum_{j\in\mathcal{O}_i} \hat{R}_{ijk}\]

The variational rate parameter becomes:

(2.10.315)¶\[\tilde{\beta}_{u_{ik}} = \beta_u + \sum_{j\in\mathcal{O}_i} \mathbb{E}_q[v_{jk}]\]

Therefore:

(2.10.316)¶\[q(u_{ik}) = \operatorname{Gamma} ( \tilde{\alpha}_{u_{ik}}, \tilde{\beta}_{u_{ik}} )\]

with posterior mean:

(2.10.317)¶\[\mathbb{E}_q[u_{ik}] = \frac{ \tilde{\alpha}_{u_{ik}} }{ \tilde{\beta}_{u_{ik}} }\]

2.10.4.53. Update for \(v_{jk}\)¶

Similarly:

(2.10.318)¶\[\tilde{\alpha}_{v_{jk}} = \alpha_v + \sum_{i\in\mathcal{O}_j} \hat{R}_{ijk}\]

and:

(2.10.319)¶\[\tilde{\beta}_{v_{jk}} = \beta_v + \sum_{i\in\mathcal{O}_j} \mathbb{E}_q[u_{ik}]\]

Therefore:

(2.10.320)¶\[q(v_{jk}) = \operatorname{Gamma} ( \tilde{\alpha}_{v_{jk}}, \tilde{\beta}_{v_{jk}} )\]

with posterior mean:

(2.10.321)¶\[\mathbb{E}_q[v_{jk}] = \frac{ \tilde{\alpha}_{v_{jk}} }{ \tilde{\beta}_{v_{jk}} }\]

2.10.4.54. Solving for the Variational Parameters¶

For \(u_{ik}\), the variational distribution is:

(2.10.322)¶\[q(u_{ik}) = \operatorname{Gamma} ( \tilde{\alpha}_{u_{ik}}, \tilde{\beta}_{u_{ik}} )\]

The expected value is:

(2.10.323)¶\[\mathbb{E}_q[u_{ik}] = \frac{ \tilde{\alpha}_{u_{ik}} }{ \tilde{\beta}_{u_{ik}} }\]

and the expected logarithm is:

(2.10.324)¶\[\mathbb{E}_q[\log u_{ik}] = \psi( \tilde{\alpha}_{u_{ik}} ) - \log \tilde{\beta}_{u_{ik}}\]

The corresponding expressions for \(v_{jk}\) are:

(2.10.325)¶\[\mathbb{E}_q[v_{jk}] = \frac{ \tilde{\alpha}_{v_{jk}} }{ \tilde{\beta}_{v_{jk}} }\]

and:

(2.10.326)¶\[\mathbb{E}_q[\log v_{jk}] = \psi( \tilde{\alpha}_{v_{jk}} ) - \log \tilde{\beta}_{v_{jk}}\]

2.10.4.55. Expected Rate¶

The expected Poisson rate is:

(2.10.327)¶\[\mathbb{E}_q[\lambda_{ij}] = \sum_k \mathbb{E}_q[u_{ik}] \mathbb{E}_q[v_{jk}]\]

or:

(2.10.328)¶\[\mathbb{E}_q[\lambda_{ij}] = \sum_k \frac{ \tilde{\alpha}_{u_{ik}} }{ \tilde{\beta}_{u_{ik}} } \frac{ \tilde{\alpha}_{v_{jk}} }{ \tilde{\beta}_{v_{jk}} }\]

This expected rate is used when updating the auxiliary responsibility variables \(\phi_{ijk}\).

2.10.4.56. Complete Variational Inference Algorithm¶

The overall algorithm can be summarized as follows.

2.10.4.57. Step 1: Initialize¶

Initialize positive variational parameters:

(2.10.329)¶\[\tilde{\alpha}_{u_{ik}}, \tilde{\beta}_{u_{ik}}, \tilde{\alpha}_{v_{jk}}, \tilde{\beta}_{v_{jk}}\]

2.10.4.58. Step 2: Compute Expected Latent Factors¶

Compute:

(2.10.330)¶\[\mathbb{E}[u_{ik}] = \frac{ \tilde{\alpha}_{u_{ik}} }{ \tilde{\beta}_{u_{ik}} }\]

and:

(2.10.331)¶\[\mathbb{E}[v_{jk}] = \frac{ \tilde{\alpha}_{v_{jk}} }{ \tilde{\beta}_{v_{jk}} }\]

2.10.4.59. Step 3: Compute Responsibilities¶

For each observed entry:

(2.10.332)¶\[\phi_{ijk} = \frac{ \mathbb{E}[u_{ik}] \mathbb{E}[v_{jk}] }{ \sum_{\ell} \mathbb{E}[u_{i\ell}] \mathbb{E}[v_{j\ell}] }\]

2.10.4.60. Step 4: Compute Expected Counts¶

(2.10.333)¶\[\hat{R}_{ijk} = R_{ij}\phi_{ijk}\]

2.10.4.61. Step 5: Update \(U\)¶

Update:

(2.10.334)¶\[\tilde{\alpha}_{u_{ik}} = \alpha_u + \sum_{j\in\mathcal{O}_i} \hat{R}_{ijk}\]

and:

(2.10.335)¶\[\tilde{\beta}_{u_{ik}} = \beta_u + \sum_{j\in\mathcal{O}_i} \mathbb{E}[v_{jk}]\]

2.10.4.62. Step 6: Update \(V\)¶

Update:

(2.10.336)¶\[\tilde{\alpha}_{v_{jk}} = \alpha_v + \sum_{i\in\mathcal{O}_j} \hat{R}_{ijk}\]

and:

(2.10.337)¶\[\tilde{\beta}_{v_{jk}} = \beta_v + \sum_{i\in\mathcal{O}_j} \mathbb{E}[u_{ik}]\]

2.10.4.63. Step 7: Repeat¶

Repeat Steps 2–6 until the ELBO or another convergence criterion stabilizes.

2.10.4.64. Summary¶

The major factorization methods discussed in this chapter differ primarily in their assumptions about the observed data.

  • PPCA uses a probabilistic model with Gaussian noise and linear latent variables.

  • Gaussian Matrix Factorization models continuous observations using Gaussian noise and latent user/item factors.

  • Poisson Matrix Factorization models count observations using Poisson distributions and non-negative latent factors.

  • Gamma Priors provide a natural Bayesian prior for non-negative latent factors.

  • Variational Inference approximates the posterior using a tractable family of distributions.

  • The ELBO provides the objective that is optimized during variational inference.

  • Auxiliary variables allow the Poisson likelihood to be handled using simpler conditional updates.

  • Gamma variational distributions provide closed-form updates for the variational shape and rate parameters.

The key distinction is the observation model:

(2.10.338)¶\[\boxed{ \text{Continuous data} \rightarrow \text{Gaussian models} }\]

and:

(2.10.339)¶\[\boxed{ \text{Count data} \rightarrow \text{Poisson models} }\]

For Bayesian Poisson Matrix Factorization:

(2.10.340)¶\[\boxed{ \text{Poisson likelihood} + \text{Gamma priors} + \text{Variational inference} \rightarrow \text{Gamma posterior approximations} }\]

This framework provides a flexible approach for modeling sparse count data while maintaining non-negative and interpretable latent representations.
